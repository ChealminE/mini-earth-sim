실시간 실험 연동 전 확인사항

아두이노에서 이 JSON 형식으로 값을 보내야 대시보드에 표시됩니다.

예시 (센서 이름은 자유롭게 정해도 됨)
{"temp": 23.4, "co2": 812.3}
아두이노 코드 (마지막 출력 부분, ArduinoJson 사용)
JsonDocument doc;
doc["temp"] = tempValue;
doc["co2"]  = co2Value;
serializeJson(doc, Serial);
Serial.println();
  • 센서 이름(키)은 자유롭게 지어도 됩니다. (temp, co2 외 다른 이름 가능)
  • 측정하는 센서만 넣으면 됩니다. 전부 다 있을 필요는 없습니다.
  • CO₂ 관련 3D 효과를 보려면 키 이름에 co2라는 글자를 포함하세요.
  • USB(우노): 9600bps + Serial.println(json) / WiFi(ESP32): /data로 JSON POST
