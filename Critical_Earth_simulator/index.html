실측 범위: 350~418ppm (1988~2023). 해양 pH는 회귀가 아니라 탄산 평형식을 직접 풀어 구합니다(관측 35점을 RMSE 0.008로 재현). 기온편차는 복사강제력이 농도의 로그에 비례하는 점을 반영해 log₂ 형태로 회귀했습니다. 그래도 실측 범위 밖은 추정치이고, 기후 시스템은 임계점을 지나면 관계가 깨질 수 있어 극단값은 참고용으로만 보세요. 이 슬라이더 값은 왼쪽 3D 씬과 1인칭 탐험 모드에도 똑같이 반영됩니다.

기온편차 = 4.258 × log₂(CO₂/280) − 1.858 (r=0.924) · 여기서 4.258°C/배증이 이 관측 기록에서 읽어낸 기후민감도입니다 (IPCC 최적추정 3.0, 범위 2.5~4.0).
해양 pH는 회귀식이 아니라 탄산 평형(K₀·K₁·K₂ + 총알칼리도 일정)을 풀어 계산합니다 — 관측 35점 RMSE 0.008.

실시간 실험 연동 전 확인사항

보드에서 이 JSON 형식으로 값을 보내야 대시보드에 표시됩니다. 어떤 보드든, 어떤 통신 방식(WiFi/USB 시리얼/BLE)이든 이 형식으로만 보내면 자동 인식됩니다.

예시 (센서 이름은 자유롭게 정해도 됨)
{"temp": 24.8, "ph": 7.21, "co2": 735}
아두이노 코드 (마지막 출력 부분, ArduinoJson 사용)
JsonDocument doc;
doc["temp"] = tempValue;
doc["ph"]   = phValue;
doc["co2"]  = co2Value;
serializeJson(doc, Serial);
Serial.println();
  • 센서 이름(키)은 자유롭게 지어도 됩니다. (temp, ph, co2 외 다른 이름 가능)
  • 측정하는 센서만 넣으면 됩니다. 전부 다 있을 필요는 없습니다.
  • 3D 효과 연동: 키 이름이 temp, ph, co2와 정확히 일치할 때만 자동으로 연결됩니다. (예: water_temp처럼 이름이 다르면 카드/그래프에는 뜨지만 3D 효과는 연결되지 않습니다)
  • 이름이 안 맞거나 같은 종류 센서가 여러 개면(예: 온도 센서 2개), 센서 카드 아래 드롭다운에서 "기온"/"수온" 등 역할을 직접 지정하면 그 값이 3D 효과에 연결됩니다.
  • 어떤 보드든 이 JSON 형식으로 보내면 자동 인식됩니다 (USB 시리얼 / BLE / WiFi MQTT / WiFi POST 전부 지원)
  • '기본 실험'의 표준 코드를 쓰면 왼쪽 아래 패널에서 센서 켜기·끄기, 측정 간격 바꾸기, 재부팅을 할 수 있습니다.

    연결 정보
    
          
    보드 코드에 넣을 주소들이에요. 노트북과 보드가 같은 와이파이에 있어야 WiFi 방식이 됩니다.
    
          
    
          
      
            
    • USB: 케이블을 꽂으면 서버가 자동으로 찾습니다. CoolTerm·아두이노 시리얼 모니터가 그 포트를 열고 있으면 못 찾아요 (한 포트는 한 프로그램만 열 수 있음).
      • 
            
    • BLE(HM-10·ESP32): 서버를 --ble 옵션으로 켜야 합니다.
      • 
            
    • HC-06(클래식 블루투스): 윈도우 설정에서 먼저 페어링하면 COM 포트가 생기고, USB와 똑같이 자동으로 잡힙니다.
      • 
            
    • WiFi가 안 붙으면 윈도우 방화벽이 1883(MQTT) 포트를 막고 있는지 확인하세요.
