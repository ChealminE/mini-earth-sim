**즉 냉수대(변경 2-1)가 없으면 Ω<1 경고는 1000ppm 슬라이더 안에서 끝내 안 켜진다** — 변경 1과 2-1은 같이 가야 의미가 있다.

### 11. 완성도 — 교육 설계 / UI / 비주얼 (2026-10-09 점검)

A방안(10절)은 **모형을 더 정확하게** 만드는 데 집중해 있다. 아래는 그와 별개로,
**정확해진 모형을 학생이 실제로 볼 수 있게** 만드는 쪽의 과제다. 둘 다 있어야 완성된다.

- [ ] **🔴 화학종 분포 시각화** — `seawaterState()`가 [CO₂(aq)]·[HCO₃⁻]·[CO₃²⁻]·DIC를 전부 계산하는데
      **`earth-model.js` 밖에서 쓰는 코드가 하나도 없다**(확인 완료). 학생이 보는 건 pH와 Ω라는 결과 숫자뿐이라
      **평형이 어느 쪽으로 이동했는지가 안 보인다.** 르샤틀리에를 가르치려면 화학종이 움직이는 걸 봐야 한다.
      미래 예측 탭에 누적 막대/면적 그래프를 붙인다. **데이터는 이미 있고 표시 코드만 붙이면 된다.**
- [ ] **🔴 탐구 과제 내장** — 튜토리얼·과제 장치가 **0건**(확인 완료). 1인칭에 떨어뜨리면 학생은 뭘 할지 모른다.
      야장은 평균·표본표준편차(n−1)까지 잘 만들어져 있는데, **왜 써야 하는지를 모르면 안 쓴다.**
      설계안 8절의 활동 ①~④ 표를 그대로 앱 안 체크리스트로 옮긴다 (새 과학 불필요).
- [ ] 완충(buffering) 설명 — pH 곡선이 아래로 휘는 이유가 모형에 자연히 들어 있는데 화면에 설명이 없다.
      "왜 바다는 생각보다 덜 산성화되나"가 CO₃²⁻ 소모로 바로 설명된다. 화학종 시각화와 같이 가면 좋다.
- [ ] 측정값 지도 시각화 — 미니맵에 야장 기록을 **색점**으로 찍으면 공간 변이(열섬·나무 밑 CO₂·냉수대)가
      한눈에 보인다. 미니맵이 이미 측정 지점을 십자로 표시하므로 색만 입히면 된다.
- [ ] **터치 조작 미지원** — 1인칭 모드에 터치 이벤트 핸들러가 **0건**(확인 완료). 포인터락+WASD 전용이라

- [ ] 조감 모드가 와이드 화면을 못 씀 — `style.css`의 `grid-template-columns: 1fr 1fr 1fr` 때문에 3D가

### 2026-07-24 (4) — 실사용 중 발견한 버그 수정
**문제:** 본인이 실제로 `run_server.bat`을 더블클릭했더니 cmd 창에 한글이 깨진 채로 "내부 또는 외부 명령이 아닙니다" 에러가 여러 줄 뜨고 서버가 안 켜짐.

**원인:** `run_server.bat`/`setup.bat`/`build_exe.bat`이 전부 **줄바꿈이 LF(유닉스식)로, BOM 없이** 저장되어 있었음. `chcp 65001`(UTF-8 콘솔 모드) + 한글 텍스트 + LF 줄바꿈 조합에서 cmd.exe가 파일을 깨진 명령 토큰으로 잘못 해석하는 문제였음. 지금까지 이 배치파일들을 이 세션(자동화 환경)에서만 테스트했었고, 실제 더블클릭 환경(진짜 콘솔)에서는 이번에 처음 검증된 것 — 그래서 여태 못 잡았음.

**완료한 작업:**
- `run_server.bat`/`setup.bat`/`build_exe.bat` 3개 전부 **CRLF 줄바꿈 + UTF-8 BOM**으로 재저장
- `.gitattributes` 신규 추가 (`*.bat text eol=crlf`) — 앞으로 이 레포를 체크아웃하는 누구의 컴퓨터에서든(로컬 git 설정과 무관하게) `.bat` 파일이 항상 CRLF로 유지되도록 강제, 재발 방지
- 수정한 `run_server.bat`을 실제로 실행해서 검증: 한글 정상 출력, 서버 정상 기동, 브라우저 자동으로 열려서 모든 리소스(index/style/js/텍스처) 200 OK로 로딩되는 것까지 확인

**2) RMSE는 0.0070 → 0.0084로 나빠졌고, 그게 의도한 결과입니다**

기본값 `T_REF = 25`에서 HOT 35점 RMSE가 0.0084(최대오차 0.0151)입니다. 18~20 °C로 내리면
0.0070을 유지하지만 **그건 관측에 맞춰 기준 수온을 고르는 것**이고, "회귀로 맞춘 게 아니라
문헌 화학 상수만 넣었는데 관측과 겹친다"는 이 모형의 핵심 주장과 정면으로 충돌합니다.
25 °C는 검증에 쓴 HOT(하와이 ALOHA) 해역의 **실제 표층 수온**이라서 그대로 두고,
대신 문서 수치를 고쳤습니다. `earth-model.js` 상단 주석에 이 판단 근거를 적어 뒀습니다.
