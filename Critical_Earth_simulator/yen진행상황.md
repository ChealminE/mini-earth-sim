### 2026-07-24 (4) — 실사용 중 발견한 버그 수정
**문제:** 본인이 실제로 `run_server.bat`을 더블클릭했더니 cmd 창에 한글이 깨진 채로 "내부 또는 외부 명령이 아닙니다" 에러가 여러 줄 뜨고 서버가 안 켜짐.

**원인:** `run_server.bat`/`setup.bat`/`build_exe.bat`이 전부 **줄바꿈이 LF(유닉스식)로, BOM 없이** 저장되어 있었음. `chcp 65001`(UTF-8 콘솔 모드) + 한글 텍스트 + LF 줄바꿈 조합에서 cmd.exe가 파일을 깨진 명령 토큰으로 잘못 해석하는 문제였음. 지금까지 이 배치파일들을 이 세션(자동화 환경)에서만 테스트했었고, 실제 더블클릭 환경(진짜 콘솔)에서는 이번에 처음 검증된 것 — 그래서 여태 못 잡았음.

**완료한 작업:**
- `run_server.bat`/`setup.bat`/`build_exe.bat` 3개 전부 **CRLF 줄바꿈 + UTF-8 BOM**으로 재저장
- `.gitattributes` 신규 추가 (`*.bat text eol=crlf`) — 앞으로 이 레포를 체크아웃하는 누구의 컴퓨터에서든(로컬 git 설정과 무관하게) `.bat` 파일이 항상 CRLF로 유지되도록 강제, 재발 방지
- 수정한 `run_server.bat`을 실제로 실행해서 검증: 한글 정상 출력, 서버 정상 기동, 브라우저 자동으로 열려서 모든 리소스(index/style/js/텍스처) 200 OK로 로딩되는 것까지 확인
