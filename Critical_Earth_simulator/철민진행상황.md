### 11. 완성도 — 교육 설계 / UI / 비주얼 (2026-10-09 점검)

A방안(10절)은 **모형을 더 정확하게** 만드는 데 집중해 있다. 아래는 그와 별개로,
**정확해진 모형을 학생이 실제로 볼 수 있게** 만드는 쪽의 과제다. 둘 다 있어야 완성된다.

- [x] **🔴 화학종 분포 시각화** (2026-10-09 밤샘) — 미래 예측 탭에 DIC=100% 누적 막대 2개(280 기준/현재) + 비율·µmol/kg·280 대비 표. 280/418/600/1000 ppm 지시서 표와 전부 일치. ↓ 원래 문제 기술 — `seawaterState()`가 [CO₂(aq)]·[HCO₃⁻]·[CO₃²⁻]·DIC를 전부 계산하는데
      **`earth-model.js` 밖에서 쓰는 코드가 하나도 없다**(확인 완료). 학생이 보는 건 pH와 Ω라는 결과 숫자뿐이라
      **평형이 어느 쪽으로 이동했는지가 안 보인다.** 르샤틀리에를 가르치려면 화학종이 움직이는 걸 봐야 한다.
      미래 예측 탭에 누적 막대/면적 그래프를 붙인다. **데이터는 이미 있고 표시 코드만 붙이면 된다.**
- [x] **🔴 탐구 과제 내장** (2026-10-09 밤샘) — 야장(F) '탐구 과제' 탭에 활동 ①~④ 카드, 판정은 야장 기록 수로만, 기록 0건일 때 '어디서부터?' 안내. ↓ 원래 문제 기술 — 튜토리얼·과제 장치가 **0건**(확인 완료). 1인칭에 떨어뜨리면 학생은 뭘 할지 모른다.
      야장은 평균·표본표준편차(n−1)까지 잘 만들어져 있는데, **왜 써야 하는지를 모르면 안 쓴다.**
      설계안 8절의 활동 ①~④ 표를 그대로 앱 안 체크리스트로 옮긴다 (새 과학 불필요).
- [x] 완충(buffering) 설명 (2026-10-09 밤샘) — 반응식 CO₂ + CO₃²⁻ + H₂O → 2HCO₃⁻ 와 'CO₃²⁻ 감소 → Ω 하락' 3문장. ↓ 원래 문제 기술 — pH 곡선이 아래로 휘는 이유가 모형에 자연히 들어 있는데 화면에 설명이 없다.
      "왜 바다는 생각보다 덜 산성화되나"가 CO₃²⁻ 소모로 바로 설명된다. 화학종 시각화와 같이 가면 좋다.
