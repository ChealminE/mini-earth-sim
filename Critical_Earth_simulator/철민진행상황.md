### 11. 완성도 — 교육 설계 / UI / 비주얼 (2026-10-09 점검)

A방안(10절)은 **모형을 더 정확하게** 만드는 데 집중해 있다. 아래는 그와 별개로,
**정확해진 모형을 학생이 실제로 볼 수 있게** 만드는 쪽의 과제다. 둘 다 있어야 완성된다.

- [ ] **🔴 화학종 분포 시각화** — `seawaterState()`가 [CO₂(aq)]·[HCO₃⁻]·[CO₃²⁻]·DIC를 전부 계산하는데
      **`earth-model.js` 밖에서 쓰는 코드가 하나도 없다**(확인 완료). 학생이 보는 건 pH와 Ω라는 결과 숫자뿐이라
      **평형이 어느 쪽으로 이동했는지가 안 보인다.** 르샤틀리에를 가르치려면 화학종이 움직이는 걸 봐야 한다.
      미래 예측 탭에 누적 막대/면적 그래프를 붙인다. **데이터는 이미 있고 표시 코드만 붙이면 된다.**
- [ ] **🔴 탐구 과제 내장** — 튜토리얼·과제 장치가 **0건**(확인 완료). 1인칭에 떨어뜨리면 학생은 뭘 할지 모른다.
      야장은 평균·표본표준편차(n−1)까지 잘 만들어져 있는데, **왜 써야 하는지를 모르면 안 쓴다.**
      설계안 8절의 활동 ①~④ 표를 그대로 앱 안 체크리스트로 옮긴다 (새 과학 불필요).
- [ ] 완충(buffering) 설명 — pH 곡선이 아래로 휘는 이유가 모형에 자연히 들어 있는데 화면에 설명이 없다.
      "왜 바다는 생각보다 덜 산성화되나"가 CO₃²⁻ 소모로 바로 설명된다. 화학종 시각화와 같이 가면 좋다.
- [ ] 측정값 지도 시각화 — 미니맵에 야장 기록을 **색점**으로 찍으면 공간 변이(열섬·나무 밑 CO₂·냉수대)가
      한눈에 보인다. 미니맵이 이미 측정 지점을 십자로 표시하므로 색만 입히면 된다.
- [ ] **터치 조작 미지원** — 1인칭 모드에 터치 이벤트 핸들러가 **0건**(확인 완료). 포인터락+WASD 전용이라
      태블릿에서 열리기만 하고 못 움직인다. 수업에서 태블릿을 쓸 계획이면 필요.
      (README의 "태블릿도 열림" 표기는 2026-10-09에 사실대로 정정함)
- [ ] 조감 모드가 와이드 화면을 못 씀 — `style.css`의 `grid-template-columns: 1fr 1fr 1fr` 때문에 3D가
      가로 1/3 고정. 1440×900에서 캔버스가 479×449로 잡히고 화면 아래 1/3이 빈 공백이다. 빔프로젝터에서 체감 큼.
- [ ] 단축키 9종(E/F/G/T/M/H/V/R/1~9) 안내가 `H` 뒤에만 있음 — 첫 진입 때 한 번은 보여줄 것.
- [ ] Ω<1 경고가 아직 한 번도 안 켜짐 — 1000ppm·25 °C에서 1.82. **변경 2-1 냉수대가 들어가야** 켜진다(2 °C에서 0.69).
      가장 극적인 장면이 아직 작동하지 않는 상태.

**1) 1인칭 탐험 모드 신설 (`firstperson/`):**
- 조감 모드는 **건드리지 않고** 지형만 복사해 별도 폴더로 구축 — 두 모드가 서로를 깨뜨리지 않게
- 포인터락 시점 조작, 걷기/달리기/점프/수영, 배기가스, 물 반사, 동물, 구름
- 측정 도구 단축바(`1`~`9`), `E`키 설정창, 도구 뷰모델을 별도 씬으로 분리해 겹침 방지

**2) 과학 모델 통일 (`js/earth-model.js` 신설) — 이 작업의 핵심:**
- 조감 모드와 1인칭 모드가 **같은 CO₂에 다른 pH를 내놓고 있었음** (1000ppm에서 7.50 vs 6.15)
- 해양 pH를 회귀식이 아니라 **탄산 평형식**(K₀·K₁·K₂ + 총알칼리도 일정)을 [H⁺]에 대한 이차식으로 직접 풀어 계산하도록 교체 — 관측 35점 RMSE 0.007로, 대체한 회귀식보다 실측에 더 잘 맞음
- 기온편차는 복사강제력이 농도의 **로그**에 비례하는 점을 반영해 log₂ 형태로 회귀
- 아라고나이트 포화도 Ω 추가 (1 미만이면 골격 용해)
- 두 모드가 이 파일 하나를 공유하므로 이제 값이 어긋날 수 없음
- 이 과정에서 `js/common.js`에 있던 자체 `CO2_MAX = 600`을 제거했는데, **실시간 실험 탭이 실제 센서값을 600ppm으로 잘라내고 있던 것**이 같이 드러났습니다 (교실 실내 CO₂는 800~1500ppm이 예사라 실측에 영향 있었을 수 있음)

**3) 1인칭 모드를 "조사 도구"로 전환:**
- 야장 — 측정 기록 누적, 횡단조사, CSV 내보내기(BOM 포함)
- 계측 오차 모델 — 분해능, 반복도(가우시안 노이즈), 1차 지연 응답. 값이 즉시 확정되지 않고 "측정 중"을 거침
- 낮밤 주기, 환경음

**4) 계절 / 날씨 / 미니맵 / 주행차량 / 동물체온 (Stage A~F):**
- 먼저 **환경 합성 레이어 리팩터**(Stage A)를 동작 변화 없이 분리 — CO₂·시간·계절·날씨가 서로 덮어쓰지 않고 곱해지도록. 이걸 먼저 해둔 덕에 이후 순서 의존 버그가 한 건도 안 났습니다
