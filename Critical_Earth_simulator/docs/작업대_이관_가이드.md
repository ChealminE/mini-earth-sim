# 작업대 이관 가이드 — 직접 실험 탭이 공용 그래프 작업대를 쓰려면

> 대상: 직접 실험 탭 담당(yen). 3차 대격변 C2에서 현재 실태 탭용 **공용 그래프 작업대**(`js/graph-workspace.js`)를 만들었다.
> 이번에 `js/tab-live.js` 는 **고치지 않았다**(3차 마스터 §4 — 옮기는 일은 합의 후 다음 작업). 이 문서는 옮길 때 무엇을 바꾸면 되는지 정리한 것이다.
> 함께 볼 문서: `docs/테마_이관_가이드.md`(작업대 CSS는 종이 테마 위에서만 켜진다 — §4).

## 1. 지금 두 그래프는 어떻게 다른가

| | 직접 실험 탭 (`tab-live.js`) | 공용 작업대 (`graph-workspace.js`) |
|---|---|---|
| 그래프 단위 | 자유 배치 카드 여러 장(`liveGraphs`, 최대 `MAX_LIVE_GRAPHS`) | 작업대 하나 = 그래프 하나, 자료 카드를 끌어 Y1·Y2(모양 비교는 3개)에 놓음 |
| 합치기 | 카드 제목 줄을 끌어 다른 카드에 놓기 → `askMerge` 확인창 → `mergeLiveGraphs` | 오른쪽 자료 카드를 그래프에 놓기(확인창 없음), 칩 [✕]로 빼기 |
| 끌기 이벤트 | `pointerdown → setPointerCapture → pointermove(elementFromPoint) → pointerup` | **같은 흐름으로 만들었다**(옮기기 쉽게). 마우스 전용, 키보드 대체(Enter/Space·[＋]·Delete) |
| 축 | ⚙ 설정에서 최소·최대·단위를 손으로(`xMin`·`yAuto` …) | 손으로 못 바꿈(규칙 R3) — 값에서 자동, `minSpan` 보장. 같은 `axis` 는 한 축(R1), 다른 축은 오른쪽 Y2(R2) |
| x축 | 시간(초·분·시, `resolveTimeUnit`) 또는 다른 센서 | **연도**(정수) — 아래 §3 |
| 산점도 | 아무 두 센서(xKey·yKey) — 같은 기록 행끼리 | Y1 대 Y2, 같은 x(연도)끼리 짝(`pairByYear`), r·n·기간 표시(R6) |
| 표시 | 다크 테마, 자유 범례 | 종이 테마, 모형 = 점선·한 지점 = 꼬리표(R7), 자료 없는 구간 빗금 |
| 내보내기 | 크게 보기 창의 PNG·CSV(`downloadGraphImage`·`downloadGraphData`) | `toImage()`(PNG dataURL), `getConfig()`(구성 JSON) → 학습지 [나의 증거](`onSend`) |

## 2. 작업대 API (한 화면에 여러 개 있어도 된다 — id를 쓰지 않고 넘겨받은 root 안에만 DOM을 만든다)

```js
const ws = GraphWorkspace.create(rootEl, {
  catalog,            // 자료 카드 목록 (아래 형식). 필수
  axes,               // { 축이름: { unit } }  — 생략하면 DATA_AXES
  hints,              // { empty, one, pairs: [{ pair: [id, id], text }] } — 생략하면 DATA_HINTS
  decks, deckNames,   // 카드 묶음 순서·이름 — 생략하면 ['core','carbon','model'], DATA_DECKS
  maxSeries,          // 시간·산점도에서 놓을 수 있는 수(기본 2). 모양 비교는 3
  onSend,             // 있으면 [학습지로 보내기] 버튼이 생기고 getConfig() 를 넘겨준다
  plugins,            // Chart.js 플러그인을 덧붙일 때 (예: 탐구 표지)
});
ws.add(id) / ws.remove(id) / ws.clear()
ws.setMode('time' | 'shape' | 'scatter') / ws.setRange('all' | 1950 | 1980) / ws.setCommonOnly(bool) / ws.setFlip(id, bool)
ws.getConfig() → { series, mode, range, commonOnly, flips }   ws.loadConfig(cfg)   // 저장은 이 JSON만 (그림 저장 금지 — 마스터 §6-8)
ws.lock(text | null)   // 탐구 단계가 구성을 고정할 때
ws.toImage() / ws.on(fn) / ws.resize() / ws.chart()
```

카드(목록 한 항목) 형식은 `js/data-catalog.js` 머리 주석에 있다:
`{ id, label, short, unit, axis, src, scope: 'global'|'station'|'model', color: '--토큰', minSpan, order, deck, get: () => [{ x, y, lo?, hi?, seg? }] }`.
계산 함수(`GraphWorkspaceCore.axisRange·commonPeriod·pairByYear·pearson…`)는 DOM이 없어 node로 검사한다(`tools/test_catalog.js`).

## 3. 직접 실험 탭에 쓰려면 바꿔야 할 것

작업대는 현재 실태(연도 자료, 고정된 자료) 기준으로 만들어서 아래 다섯 곳이 연도·고정 자료를 가정한다. **작업대 쪽에 옵션을 더하는 방식**을 권한다(현재 실태 동작은 그대로).

1. **x 단위 (연도 → 시간)** — `graph-workspace.js` 에서 '년'이 들어간 문구 10곳(자료 없음 `(○○년부터)`, 툴팁 `○○년 · …`, 산점도 기간 등)과
   x축 눈금 `callback: v => String(v)`. → `opts.x = { label: '시간', unit: 's', fmt: v => … }` 같은 옵션을 받아 문구를 만들게 한다.
   직접 실험 탭의 시간 단위 자동 고르기(`resolveTimeUnit`)는 카드 `get()` 안에서 x를 그 단위로 바꿔 넘기면 작업대는 몰라도 된다.
2. **기간 버튼** — `RANGES = ['all', 1950, 1980]`(규칙 R8)이 고정. → `opts.ranges`(예: `['all', -60, -300]` = 최근 1분·5분)로 받게 한다.
   실험은 길이가 매번 달라 '처음부터 / 최근 n분'이 맞다.
3. **자료 캐시** — `makeEnv` 가 목록(catalog)마다 `get()` 결과를 **한 번만** 만들어 둔다(모형 실행을 아끼려고). 실시간으로 값이 들어오는 센서에는 맞지 않는다.
   → `ws.refresh(id?)`(캐시 지우고 다시 그림)를 더하고, 값이 들어올 때(`updateLiveChart` 를 부르는 곳) 함께 부른다. 너무 잦으면 묶어서(예: 1초에 한 번).
4. **산점도 짝짓기** — `pairByYear` 는 x가 **정확히 같은** 점끼리 짝짓는다. 센서 둘이 한 기록 행(`liveRecords` 의 같은 `_t`)에 같이 오면 그대로 맞는다.
   보드가 다르면 시각이 조금씩 어긋나므로 그때는 `seriesPoints(yKeyA, yKeyB)` 처럼 **기록 행에서 바로 짝지은 점**을 넘기는 별도 경로가 필요하다
   (지금 탭의 `seriesPoints(xKey, yKey)` 가 이미 그 일을 한다 — 작업대 산점도에 `opts.pairs(idA, idB)` 훅을 두는 안).
5. **출처(`src`)** — 작업대는 카드·축·증거에 `js/sources.js` 출처를 따라 붙이고, `check_sources.js` 는 목록의 모든 `src` 키가 등록부에 있는지 본다.
   학생이 잰 값에는 출처 키가 없다. → `src` 를 빈 배열로 두면 출처 줄을 생략하도록(지금 `srcKeys` 는 `[].concat(it.src)`), `scope: 'measured'`(꼬리표 '직접 측정') 추가.

센서 카드는 이렇게 만들면 된다(예시, 실제 키 이름은 탭의 센서 목록에서):

```js
const liveCatalog = sensorKeys.map((key, i) => ({
  id: key, label: key, short: key, unit: unitOf(key), axis: unitOf(key) || key,   // 같은 단위끼리 한 축 (R1)
  src: [], scope: 'measured', color: `--data-live-${i % 6}`, minSpan: minSpanOf(key), order: i, deck: 'live',
  get: () => seriesPoints(TIME_AXIS_KEY, key, 'auto'),     // 지금 탭의 함수 그대로
}));
```

- `axis` 를 단위로 두면 온도 센서 두 개는 한 축, 온도와 CO₂ 센서는 Y1·Y2로 자동으로 갈린다(지금 탭에서 ⚙로 하던 일).
- `minSpan` 은 센서 분해능에 맞춘다(예: 온도 0.5 °C, CO₂ 50 ppm). 작은 잡음이 큰 변화처럼 보이지 않게 하는 값이다.
- 색 토큰은 `css/theme.css` 에 새로 만들고 `tools/check_contrast.js` 목록에도 넣는다(3:1 이상).

## 4. 화면·CSS

- 작업대 CSS(`.gw-*`)는 전부 `css/paper.css` 의 `body.paper` 아래에 있다. 직접 실험 탭은 아직 `body.paper` 가 아니라서
  **작업대를 넣어도 모양이 안 잡힌다.** 순서는 `docs/테마_이관_가이드.md` §2(`PAPER_TABS` 에 `'live'`) → 작업대.
- 작업대는 오른쪽에 카드 목록(약 1/4 폭)을 둔다. 지금 직접 실험 탭의 자유 배치 카드 여러 장을 그대로 두고 싶으면
  **카드 한 장 = 작업대 하나**로 바꾸는 안(카드 안에 `create`, 목록은 접어 둠)과, 분석 칸(`live-analysis.js`)에만 작업대를 쓰는 안이 있다.
- 크기가 바뀌면 `ws.resize()` 를 부른다(현재 실태는 `resizeCurrentGraphs()` 에서 부름 — `js/tab-current.js`).

## 5. 그대로 가져가면 좋은 것 / 남겨 둘 것

- **가져가면 좋은 것**: 축 자동(R1~R3)·뒤집기 기록(R4)·모양 비교(R5)·산점도 r(R6) — 직접 측정 자료로 '증거'를 만들 때 축 조작으로 상관을 꾸며 낼 수 없게 하는 장치들.
  학습지 [나의 증거]로 보내기(`onSend` → `Worksheet.addEvidence(kind, cfg)`, `Worksheet.registerEvidenceKind` 로 다시 그리는 법 등록 — `js/tab-current.js` 의 'workspace' 참고).
- **남겨 둘 것**: 축 손 조절·보조선(marks)·크게 보기 창의 편집 — 실험 분석에는 필요하다. 작업대 옵션으로 넣지 말고 크게 보기 창(`openGraphWin`)에 그대로 둔다.
- 확인창(`askMerge`)은 작업대에 없다(놓으면 바로 들어가고 [✕]로 뺀다). 되돌리기가 쉬워서 확인창을 두지 않았다.
