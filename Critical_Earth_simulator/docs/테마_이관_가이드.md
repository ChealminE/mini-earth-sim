# 테마 이관 가이드 — 직접 실험 탭을 종이(라이트) 테마로 옮기기

> 대상: 직접 실험 탭 담당(yen). 2차 개편 B 단계에서 현재 실태·미래 예측·시작 화면을 라이트 테마로 바꿨고,
> **직접 실험 탭은 손대지 않았다.** 이 문서는 그 탭을 같은 체계로 옮길 때 필요한 것을 모은 것이다.
> 아래 "하드코딩 색 목록"은 `python tools/list_live_colors.py` 로 뽑은 결과다(파일이 바뀌면 다시 뽑을 것).

## 1. 지금 구조 — 테마는 `body.paper` 아래에서만 켜진다

| 파일 | 역할 |
|---|---|
| `css/theme.css` | 토큰(`:root` 변수) + 공통 부품(`.btn`, `.readout`, `.src-i`·`.src-tip`). `style.css` **앞**에 읽는다 |
| `css/paper.css` | 종이 테마 화면 배치(머리줄 `#topbar`, 현재 실태·미래 예측 그리드). `style.css` **뒤**에 읽는다. 모든 규칙이 `body.paper …` |
| `js/theme.js` | `Theme.color('--ink')`, `Theme.alpha(c, a)`, `Theme.hex('--paper')`(three.js), `Theme.axis()`·`Theme.legend()`(Chart.js) |
| `js/icons.js` | 인라인 SVG 아이콘 `Icons.svg('globe')`, 마크업의 `<span data-icon="globe">` 는 `Icons.fill()` 이 채운다 |
| `js/source-tip.js` | ⓘ 출처 상자. `srcButton('키')` 또는 `<button class="src-i" data-src="키">` |
| `js/main.js` | `PAPER_TABS` 에 든 탭에서만 `body.paper` 를 붙이고, 3D 바탕을 `--paper` 로, `setCameraFit()` 을 켠다 |
| `js/common.js` | `setSceneBackdrop(hex)`(3D 바탕), `LIVE_BACKDROP = 0x000000`(직접 실험 탭이 지금 쓰는 검정), `setCameraFit(a)` |

**보호 규칙에 대해.** 지시서(B §6)는 공유 선택자를 라이트로 바꾸면 `#tab-live` 범위로 다크 값을 고정하는 임시 보호 규칙을 두라고 했다.
이번에는 라이트 규칙을 처음부터 `body.paper` 아래에만 써서, 직접 실험 탭(`body.paper` 없음)에는 **아무 규칙도 새로 걸리지 않는다.**
그래서 `theme.css` 끝의 보호 규칙은 만들지 않았다(지울 것도 없다). 직접 실험 탭에 `body.paper` 를 붙이는 순간부터 새 테마가 적용된다.

## 2. 옮기는 순서 (제안)

1. `js/main.js` 의 `PAPER_TABS` 에 `'live'` 를 넣는다 → 머리줄·종이 바탕·3D 바탕색이 직접 실험 탭에도 적용된다.
   - `#topbar` 는 지금 `body.paper` 에서만 보인다. 실험 준비·실험 화면(`body.live-setup`, `body.live-run`)은 3D를 화면 가득 까는 고정 배치라
     머리줄 높이만큼 `top` 을 내려야 한다(`#liveSetup`, `#liveRun`, `body.live-* #gl-container`).
2. `style.css` 의 직접 실험 규칙에서 아래 표의 색을 토큰으로 바꾼다(`var(--…)`). 글자 크기는 `--fs-1`(13.2 px) 이상으로.
3. 조작 요소를 `.btn` + 영역 클래스로 바꾼다. 직접 실험 탭의 조작은 대부분 **기록**(`--ctl-rec`: 실험 시작·정지·CSV·지우기)과
   **이동**(`--ctl-nav`: 단계 이동·처음으로)이다. 그래프 열기·보조선은 **보기**(`--ctl-view`).
4. Chart.js 옵션의 `textColor`·`gridColor`(common.js 전역 상수) 대신 `Theme.axis()` / `Theme.color()` 를 쓴다. `Chart.defaults` 는 바꾸지 않는다.
5. `node tools/check_contrast.js`(토큰 대비), `node tools/check_sources.js`(ⓘ 키) 를 돌린다.

## 4. 버튼 클래스 사용 예

```html
<!-- 기본 · 마우스 올림(바탕 한 단계 짙게) · 눌림(aria-pressed="true" 또는 .is-on, 영역색 채움) · 포커스(2 px 윤곽선) · 사용 불가(disabled) -->
<button class="btn btn--rec" type="button"><span data-icon="record"></span>실험 시작</button>
<button class="btn btn--rec" type="button" aria-pressed="true">기록 중</button>
<button class="btn btn--nav" type="button" disabled>다음 →</button>
<button class="btn btn--view btn--stack" type="button"><span data-icon="lines"></span><span class="btn-sub">그래프</span></button>
<input type="range" class="range range--time">
<select class="select select--time">…</select>
<!-- 정보(누를 수 없음)는 평평한 글자 -->
<span class="readout">측정 간격 <b>2 s</b></span>
```

- 아이콘 버튼도 글자 레이블을 함께 단다. 이모지는 쓰지 않는다(OS마다 모양이 다르다).
- 영역 5색: 이동 `--ctl-nav`(먹) · 시간 `--ctl-time`(파랑) · 시나리오·정책 `--ctl-scen`(초록) · 보기 `--ctl-view`(보라) · 기록 `--ctl-rec`(주황).

## 5. ⓘ 부착 예

```html
<div class="chart-title">CO₂ 농도<button class="src-i" type="button" data-src="co2_noaa_gl" aria-label="출처 보기: 대기 CO₂ 지구 평균">ⓘ</button></div>
```
```js
el.innerHTML = '센서 CO₂ ' + srcButton('sensor_scd41');   // 키는 js/sources.js 에 먼저 등록
```
- 센서 값처럼 새 수치를 화면에 내면 `js/sources.js` 에 항목을 추가한다(`kind: 'obs'`, 센서 데이터시트를 `url` 로).
- `node tools/check_sources.js` 가 화면의 `data-src` / `srcButton('…')` 키가 등록부에 있는지 검사한다(단일 HTML 빌드 전에 자동 실행).
