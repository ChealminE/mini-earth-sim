# 미니 지구 모델 — 학생용 실행 가이드

아두이노(ESP32/우노) 센서 값을 3D 미니 지구 시뮬레이션에 실시간으로 연동하는 프로그램입니다.

## 1. 다운로드 & 실행 (파이썬 설치 필요 없음)

이 저장소의 **GitHub Releases** 페이지에서 **`MiniEarthModel.exe`** 파일을 다운로드하세요.
파이썬도, 별도 설치 과정도 필요 없습니다 — **파일 하나에 실행에 필요한 모든 게 들어있습니다.**

실행하려면 그 파일을 더블클릭하면 끝입니다. 처음이든 그다음이든 항상 이 파일 하나만 실행하면 됩니다.

- 검은 터미널 창이 뜨고, 잠시 후 브라우저가 자동으로 열립니다
- **이 터미널 창을 닫으면 실험이 종료**되니, 실험하는 동안은 계속 켜두세요
- 데이터 로그(`data_log.csv`)는 exe 파일이 있는 폴더에 저장됩니다

### 처음 실행할 때 뜨는 경고 창들 (정상입니다)

| 경고 | 이유 / 조치 |
|---|---|
| "Windows에서 PC를 보호했습니다" (SmartScreen) | 서명되지 않은 프로그램이라 뜨는 일반적인 경고입니다. **`추가 정보` → `실행`**을 누르세요 |
| Windows 방화벽 "액세스를 허용하시겠습니까?" | 서버가 네트워크로 아두이노 데이터를 받으려면 필요합니다. **`액세스 허용`**을 누르세요 |

## 2. 실시간 실험 탭 사용법

1. 시뮬레이션 화면에서 **"실시간 실험"** 탭으로 이동
2. **"기본 실험"** 버튼을 누르면 보드/연결방식별 예제 코드와 회로도를 볼 수 있어요 — `.ino` 코드를 다운로드해서 Arduino IDE에서 열고, 회로도대로 연결하면 됩니다
3. 아두이노를 업로드/연결한 뒤 **"실험 시작"** 버튼을 누르면 데이터 연동이 시작됩니다
4. 직접 작성한 코드를 쓰고 싶다면, JSON 형식 안내 모달을 참고해서 자유롭게 센서 값을 보내면 자동으로 인식됩니다 (키 이름 자유)

## 문제 해결

| 증상 | 원인/해결 |
|---|---|
| 화면이 새까맣게 나옴 / 텍스처가 안 보임 | `index.html`을 직접 더블클릭해서 연 경우 발생 (브라우저 보안 정책). 반드시 `MiniEarthModel.exe`로 서버를 켠 뒤, 자동으로 열리는 `http://localhost:8000` 주소로 접속하세요 |
| 실시간 실험 탭에 데이터가 안 뜸 | `MiniEarthModel.exe` 터미널 창이 켜져 있는지, 아두이노가 연결/업로드되어 있는지 확인 |
| 우노(USB) 연결이 안 잡힘 | Arduino IDE의 시리얼 모니터가 켜져 있으면 포트가 겹쳐서 안 잡힙니다. 꺼주세요 |
| 방화벽 경고를 실수로 "취소"함 | 안드로이드 앱처럼 재설치할 필요 없이, Windows 설정 → 개인정보 및 보안 → 방화벽에서 `MiniEarthModel`을 찾아 허용으로 바꾸면 됩니다 |

## 개발자/동료용: 소스에서 직접 실행하기

exe를 새로 빌드하거나 코드를 직접 수정하며 테스트할 때는 아래 방식을 씁니다 (파이썬 설치 필요).

1. **`setup.bat`** 더블클릭 — 가상환경 생성 + 라이브러리 설치, 완료되면 바탕화면에 바로가기 생성
2. **`run_server.bat`** 더블클릭 (또는 바탕화면 바로가기) — 서버 실행
3. 코드를 바꿨다면 **`build_exe.bat`**을 실행해서 `dist/MiniEarthModel.exe`를 다시 만든 뒤, GitHub Releases에 새로 업로드
