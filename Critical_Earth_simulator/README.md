# 미니 지구 모델 — 학생용 실행 가이드

CO₂ 농도에 따라 기온·해양 산성화가 어떻게 달라지는지 3D 미니 지구로 살펴보고, 아두이노(ESP32/우노) 센서 값을 실시간으로 연동할 수 있는 프로그램입니다.

## 어떤 걸 받아야 하나요?

**둘 중 하나만** 받으면 됩니다. 센서를 안 쓴다면 1번이 훨씬 간단합니다.

| | **1. `MiniEarth.html`** (단일 파일) | **2. `MiniEarthModel.exe`** (서버 포함) |
|---|---|---|
| 버전 | v1.1.0 (2026-10-09) | v1.0.0 (2026-07-23) |
| 크기 | 5.7MB | 13.7MB |
| 설치 | 없음 — 더블클릭 | 없음 — 더블클릭 |
| 인터넷 | 필요 없음 | 필요 없음 |
| 현재 실태 / 미래 예측 | ✅ | ✅ |
| 시작 화면 | ✅ | ❌ (아래 참고) |
| 1인칭 탐험 | ✅ | ❌ (아래 참고) |
| **실시간 센서 측정** | ❌ | ✅ |
| 윈도우 전용? | 아니요 (맥에서도 열림) | 네 |
| 태블릿 | 그래프 화면은 됨 / **탐험 모드는 조작 불가** (아래 참고) | 네 |

[**→ Releases 페이지에서 다운로드**](https://github.com/ChealminE/mini-earth-sim/releases/latest)

> 센서를 쓰면서 1인칭 탐험까지 보려면, 지금은 소스를 받아 `run_server.bat`으로 실행해야 합니다

## 1. `MiniEarth.html` — 센서 없이 화면만 볼 때

파일 하나를 **더블클릭**하면 브라우저에서 바로 열립니다. 카톡·메일로 받아도, USB로 옮겨도 그대로 열립니다.

시작 화면에서 보고 싶은 걸 고르세요.

| 화면 | 내용 |
|---|---|
| **현재 실태** | 1988~2023년 CO₂ 농도·기온편차·해양 pH·화석연료 배출 실측 데이터 |
| **미래 예측** | 1750~2200년 타임라인 재생. 자연만 있는 지구(배출 0)와 인간활동 지구를 좌우로 비교. 배출 시나리오(현재 추세·파리협약·2050 탄소중립) 또는 레버 6개로 직접 설계 → 배출이 대기·바다·토양으로 나뉘며 CO₂·기온·해수온·pH·Ω가 계산됨. 농도 고정 모드, 관측 계절, 측정 기록(CSV) |
| **직접 실험** | 이 파일에서는 쓸 수 없습니다 (아래 2번 필요) |
| **탐험** | 1인칭 시점으로 걸어다니며 직접 측정 |

> **왜 센서는 안 되나요?** 센서 값은 `MiniEarthModel.exe` 안의 서버가 USB/WiFi/BLE로 받아서 화면에 중계합니다. 파일 하나에는 그 서버가 없습니다.

## 2. `MiniEarthModel.exe` — 센서까지 쓸 때

더블클릭하면 검은 터미널 창이 뜨고, 잠시 후 브라우저가 자동으로 열립니다.

- **이 터미널 창을 닫으면 실험이 종료**되니, 실험하는 동안은 계속 켜두세요
- 데이터 로그(`data_log.csv`)는 exe 파일이 있는 폴더에 저장됩니다

### 처음 실행할 때 뜨는 경고 창들 (정상입니다)

| 경고 | 이유 / 조치 |
|---|---|
| "Windows에서 PC를 보호했습니다" (SmartScreen) | 서명되지 않은 프로그램이라 뜨는 일반적인 경고입니다. **`추가 정보` → `실행`**을 누르세요 |
| Windows 방화벽 "액세스를 허용하시겠습니까?" | 서버가 네트워크로 아두이노 데이터를 받으려면 필요합니다. **`액세스 허용`**을 누르세요 |

### 직접 실험 탭 사용법

**실험 준비** (아크릴 모형을 화면 가득 띄운 채로 단계별로 진행 — 준비 내용은 저장되니 IDE에 업로드하러 갔다 와도 이어서 하면 돼요)

1. 시작 화면에서 **"직접 실험"** → **실험 이름**을 정합니다. 코드·엑셀·그래프 등 받는 파일 이름 앞에 자동으로 붙어요
2. **기본 실험** 또는 **자유 실험**을 고릅니다
   - **기본 실험**: ① 보드 종류 → 통신 방식 → 연결한 센서를 골라 보드를 추가 (여러 대 가능, 보드 이름은 겹치지 않게 자동으로 붙음) → ② **실험 설계**: *보드 코드에 들어가는 설정*(측정 간격·측정 시간·핀·와이파이 — 바꾸면 다시 업로드)과 *시뮬레이션 설정*(자동 시작 조건 예: CO₂ ≥ 8000 · 자동 종료 예: 6시간 — 시작 전까지 언제든 변경) → ③ **회로도**(핀맵, 바꾼 핀 표시) → ④ **코드 받기**(고친 코드 다운로드 + 업로드 안내)
     - 제목이 **[표준·원격 제어]** 인 코드를 쓰면 실험 중에 센서 켜기·끄기, 측정 간격 바꾸기, 재부팅을 할 수 있어요
   - **자유 실험**: 센서 개수·조합 제한 없이 직접 만든 코드로 실험해요. 보드가 `{"co2": 812, "temp": 24.1}` 같은 JSON 한 줄을 보내기만 하면 돼요
3. **센서 배치**: 보드가 연결됐는지(✅/⏳) 확인한 뒤, 센서(부품)를 끌어서 아크릴 모형의 **실제로 놓은 자리**(습지·토양·해양·대기·도시)에 놓아요. 놓으면 `SCD30 → 도시 · CO₂ · 온도 · 습도`처럼 한 줄로 정리되고, 센서 이름을 누르면 무엇을 재는지(CO₂·온도·습도·pH·메탄·기타 직접 입력) 고를 수 있어요
4. 오른쪽 아래 **"▶ 실험 시작"**

처음 화면에서 **📄 기본 코드·회로도 받기**(코드 설정을 고쳐 수정본/원본 코드와 회로도 PNG 받기) 또는 **▶ 실험 시작**을 고릅니다. **📂 지난 데이터 열기**로 내보낸 엑셀·CSV를 다시 열어 편집·분석만 할 수도 있어요.

**실험 화면** (준비 때처럼 아크릴이 화면 가득 · 위쪽 상태 줄 · 오른쪽 보드·센서)

5. 오른쪽의 **센서 값 카드를 누르면** 그 센서의 그래프가 아크릴 위에 작은 창으로 떠요. 제목 줄을 끌어 아무 데나 옮기고, 모서리로 크기를 바꾸고, **다른 그래프 위에 놓으면 합쳐져요** (⚙에서 다시 나눌 수 있음). '정리'를 누르면 가지런히 놓이고, 그래프 구성은 새로고침해도 그대로예요. 기록 중에 새로고침해도 기록은 이어집니다
6. **그래프를 누르면 큰 창**이 열려요: **그래프**(점을 누르면 값 마크) / **데이터 표** / **편집·분석**(구간 자르기 · 이상값 빼기 · N개씩 묶어 평균 · 이동 평균, 통계와 추세식(직선·이차식·지수·로그 등, R²), **엑셀(.xlsx)** 저장)
7. 위쪽 **"실험 준비"** 로 돌아가면 배치를 바꾸거나 새 실험을 준비할 수 있어요

실험 한 번의 기록은 `logs/실험이름_날짜_시각.csv` 로도 자동 저장됩니다 (exe 옆 폴더).

## 1인칭 탐험 모드 조작법

`MiniEarth.html`의 시작 화면에서 **"탐험"**으로 들어갑니다 (소스로 실행한 경우도 동일).
화면을 클릭하면 마우스로 시점을 조작할 수 있고, **ESC**를 누르면 마우스가 풀립니다.

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 / `Shift` 달리기 / `Space` 점프 |
| `1`~`9` | 측정 도구 선택 (온도계·pH·CO₂·해수분석기) |
| 마우스 좌클릭 | 겨눈 곳 측정 |
| `F` | 야장 열기 (탐구 과제 4개, 측정 기록, CSV로 내보내기 가능) |
| `M` | 미니맵 크기 전환 |
| `E` | 설정 (계절·날씨·시간) |
| `H` | 도움말 |

온도는 해수·빙하·해변·녹지·도시·대기를 구분해서 재고, CO₂는 해양·녹지·도심이 다르게 나옵니다. **나무 바로 옆에서 재면 특히 낮게** 나오고, 밤에는 반대로 높아집니다. 동물을 겨누면 체온이 나오는데, 포유류와 어류가 다르게 반응합니다.

## 문제 해결

| 증상 | 원인/해결 |
|---|---|
| **`index.html`을 더블클릭했더니** 화면이 새까맣고 텍스처가 안 보임 | 소스의 `index.html`은 서버가 있어야 동작합니다 (브라우저 보안 정책). 학생용으로 받은 **`MiniEarth.html`은 더블클릭이 맞습니다** — 둘을 헷갈리지 마세요. 센서를 쓸 거면 `MiniEarthModel.exe`를 켠 뒤 자동으로 열리는 `http://localhost:8000`으로 접속하세요 |
| 실시간 실험 탭에 데이터가 안 뜸 | `MiniEarthModel.exe` 터미널 창이 켜져 있는지, 아두이노가 연결/업로드되어 있는지 확인 |
| 단일 파일 버전에서 "직접 실험"이 눌리지 않음 | 정상입니다. 센서 측정은 `MiniEarthModel.exe`가 필요합니다 |
| 우노(USB) 연결이 안 잡힘 | Arduino IDE의 시리얼 모니터·CoolTerm이 켜져 있으면 포트가 겹쳐서 안 잡힙니다. 끄고 **⟳ 포트 다시 찾기** |
| ESP32가 WiFi(MQTT)로 안 붙음 | 노트북과 같은 **2.4GHz** 와이파이인지, 코드의 `MQTT_SERVER`가 **ⓘ 연결 정보**의 주소와 같은지 확인. 학교 와이파이는 기기끼리 통신을 막는 경우가 많아서 휴대폰 핫스팟이 확실합니다 |
| 방화벽 경고를 실수로 "취소"함 | 재설치할 필요 없이, Windows 설정 → 개인정보 및 보안 → 방화벽에서 `MiniEarthModel`을 찾아 허용으로 바꾸면 됩니다 |
| 1인칭 탐험이 버벅임 | 설정(`E`)에서 날씨를 "맑음"으로 두면 가벼워집니다 |
| **태블릿에서 탐험 모드가 안 움직임** | 현재 탐험 모드는 **키보드와 마우스 전용**입니다(WASD 이동 + 마우스 시점). 터치 조작은 아직 지원하지 않습니다. 태블릿에서는 "현재 실태"·"미래 예측" 화면만 쓰세요 |

## 개발자/동료용: 소스에서 직접 실행하기

exe를 새로 빌드하거나 코드를 직접 수정하며 테스트할 때는 아래 방식을 씁니다 (파이썬 설치 필요).

1. **`setup.bat`** 더블클릭 — 가상환경 생성 + 라이브러리 설치, 완료되면 바탕화면에 바로가기 생성
2. **`run_server.bat`** 더블클릭 (또는 바탕화면 바로가기) — 서버 실행 후 `http://127.0.0.1:8000`
3. 코드를 바꿨다면 배포본을 다시 만듭니다

| 빌드 | 명령 | 결과물 |
|---|---|---|
| 단일 HTML | **`build_html.bat`** | `dist/MiniEarth.html` (5.7MB) |
| 실행 파일 | **`build_exe.bat`** | `dist/MiniEarthModel.exe` |

둘 다 `dist/`는 `.gitignore` 대상입니다 — 배포는 GitHub Releases에 업로드하는 방식입니다.

**보드 없이 직접 실험 탭 시험하기:** 서버를 켠 상태에서 `.venv\Scripts\python tools\fake_device.py` 를 실행하면 가짜 ESP32가 MQTT로 CO₂·온도 값을 보내고 화면의 명령(켜기·끄기·간격·재부팅)에 반응합니다. `--spike 120` 을 붙이면 2분 뒤 CO₂가 8000ppm 넘게 치솟아 자동 시작 조건을 시험할 수 있습니다.

**MQTT 브로커:** `server.py` 를 켜면 MQTT 브로커(1883 포트)도 같이 켜집니다(`mqtt_broker.py`). 1883을 이미 Mosquitto가 쓰고 있으면 자동으로 그쪽에 붙고, 직접 지정하려면 `--mqtt-host 주소`, 끄려면 `--no-mqtt`.

### 화면 구성

| 경로 | 내용 |
|---|---|
| `/` | 시작 화면 (`select.html`) |
| `/dashboard?tab=current\|future\|live` | 조감 모드 3개 탭 (`index.html` + `js/`) |
| `/firstperson/` | 1인칭 탐험 모드 (`firstperson/`) |

조감 모드와 1인칭 모드는 **같은 해수 화학(`js/earth-model.js`)을 공유**합니다. 해양 pH는 회귀식이 아니라 탄산 평형식(K₀·K₁·K₂ + 총알칼리도 일정)을 직접 풀어 구합니다(관측 35점 RMSE 0.008). 이 파일을 고치면 **두 모드에 동시에 반영**되므로, 한쪽만 바꿔서 두 화면이 다른 값을 내놓는 일이 없도록 여기서만 수정하세요.

조감 모드의 미래 예측·현재 실태 모형선은 **지구 시스템 엔진(`js/earth-system.js`)**을 씁니다. 배출량(`data/*.csv` → `js/earth-data.js`)을 4상자 탄소순환(대기·표층 바다·심층 바다·토양과 식생)에 넣어 시간에 따라 적분하고, 기온은 2층 에너지 균형(복사강제력 5.35·ln(CO₂/278))으로 계산합니다. 지구 평균 CO₂(1988~2023)를 RMSE 2.8 ppm으로 재현합니다. 1인칭 모드는 아직 예전 log₂ 기온 회귀(`climateAnomaly`)를 쓰며, 다음 작업에서 엔진과 연동합니다.

- 참조 구현(파이썬): `tools/earth_system_ref/engine.py` — 식을 고칠 때는 여기부터 고치고 대조 테스트로 JS와 맞춥니다
- 대조 테스트: `node tools/test_earth_system.js` (파이썬+numpy 필요)
- 데이터를 고칠 때: `data/*.csv`를 고친 뒤 `python tools/gen_earth_data.py`로 `js/earth-data.js`를 다시 만듭니다

단일 HTML 빌드는 두 모드를 각각 iframe에 넣어 전역 스코프와 CSS를 분리합니다(두 모드가 같은 `earth-model.js`를 읽어 상수가 중복 선언되는 것을 피하기 위함). 자세한 내용은 `tools/build_single_html.py` 상단 주석에 있습니다.
