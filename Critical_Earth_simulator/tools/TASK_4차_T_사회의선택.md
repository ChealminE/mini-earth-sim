# 4차 T — 사회의 선택: 정책 · 기후테크 · 자연 기반 해법

> 마스터 규칙을 따른다. 이 단계의 목적: 1인칭 탐험의 3장 **'결정자'** 를 만든다.
> 학생이 '현재(2026)'의 시청 **기후 정책 회의실**에서 정책·기후테크 카드로 2050년 사회를 설계하면, 미래 세계가 구역마다 바뀐다(해상풍력·지붕 태양광·포집 설비·숲·잘피밭). 학생은 그 미래로 가서 직접 잰다.
> 개인 행동(F·M)과 비교하면 **규모의 차이**가 드러난다. 이것이 F §0의 '③ 사회의 선택' 층이다.
> 숫자·근거는 `docs/refs/4차_문헌값.md` **6부**. 2026-11-15 추가 요청(인류의 구조 전환 노력·기후테크)에서 왔다.

## 0. 원칙

1. **엔진에 있는 것만 숫자로 바꾼다.** 엔진(`js/earth-system.js`)의 직접 설계 레버는 7개다: 전력 구성(화석·원자력·재생 비중), 전기차 비율, 탄소 포집(GtC/년), 기타 부문 감축 비율, 산림(토지이용 배출). **엔진 구조·`PARAMS`·레버 식은 바꾸지 않는다**(마스터 §4).
   레버에 대응하지 않는 항목(탄소 가격제, 기후 금융, 블루카본, 대체육, 화학적 재활용 등)은 **숫자를 지어내지 않는다.** '정책 카드'(§2-2)나 '기후테크 도감'(§2-3)으로 넣는다.
2. **쟁점은 양쪽을 같이 보인다.** 원자력·SMR, 탄소세, CCUS·DAC, 재생에너지 부지 같은 사회적 쟁점은 카드마다 **찬성 근거·우려 근거를 같은 분량으로** 적는다. 프로그램이 정답을 정해 주지 않는다. 문구 점검으로 한쪽만 좋게 쓰는 표현을 걸러 낸다(§7-4).
3. **기술 만능 경계.** 포집(CCUS·DAC) 카드는 "줄이기 어려운 배출을 위한 것, 배출을 계속해도 된다는 뜻이 아니다"를 함께 보인다. 엔진 결과도 이를 보여 준다(6부 6-3: 포집 최대 3 GtC/년만으로는 2100년 2.15 °C).
4. **정직한 규모**(F §0 그대로). 사회의 선택은 개인 행동보다 수백~수천 배 크다. 이 비교가 3장의 핵심 학습 내용이다.
5. **중·고등 모드**(마스터 D15). 중학생은 카드 3단계와 세계 변화 관찰 중심이고, 숫자는 접어 둔다. 고등학생은 레버 수치·측정 통계·그래프까지 본다.

## 1. 실행 가능성 — 첨부 목록의 처리 (2026-11-15 검토)

| 첨부 항목 | 엔진 연결 | 1인칭 표현 | 판정 | 4차 |
|---|---|---|---|---|
| 태양광·풍력 | 전력 구성 `renewShare` | 지붕 태양광(도시), 해상풍력(바다) | 높음 | **P1** |
| 소형모듈원전(SMR)·원자력 | 전력 구성 `nuclearShare` | 도시 끝 SMR 모듈 건물 | 높음, 쟁점 | **P1**(쟁점 카드, D17) |
| 석탄·석유 발전 단계적 폐쇄 | `fossilShare` = 1 − 원자력 − 재생 | 굴뚝 수·연기(C5 `stackLevel`) | 높음 | **P1** |
| 전기차·차세대 배터리 | `ev` | 도로 차량(C5) + 충전소 | 높음 | **P1** |
| CCUS(공장 굴뚝 포집) | `ccs` 일부 | 굴뚝 옆 포집 설비 | 높음, 쟁점 | **P1** |
| 직접공기포집(DAC) | `ccs` 일부 | 팬 벽 유닛(지금 1인칭 `towerFan` 자리) | 높음, 쟁점 | **P1** |
| 산림 복원(NbS) | `forest`(토지이용 배출 1.30 → −1.0 GtC/년) | 녹지 구역 나무 수 | 높음 | **P1** |
| 수소환원제철·저탄소 시멘트 | `otherCut` 안의 산업 몫(분리 계산 불가 — §2-1) | 제철소 수소 탱크, 연기 감소 | 중간 | **P1**(기타 감축 카드의 하위 설명) |
| 지속가능항공유(SAF)·선박 연료 | `otherCut` 안의 항공·해운 몫 | 하늘 비행기·바다 선박 표시 | 중간 | **P1**(기타 감축의 하위 설명) |
| ESS·스마트그리드 | 직접 배출 없음 | 도시 ESS 컨테이너. 재생 비중이 크면 '조건' 알림 | 중간 | **P2** |
| 탄소 가격제·배출권·CBAM | 직접 없음(엔진에 경제 없음) | 정책 카드 = 기술 카드의 최대 단계를 여는 **열쇠**(연출, D16) | 중간 | **P1**(정책 카드) |
| 국제 협약·NDC | 비교 경로로 계산 가능(§2-4) | 회의실 화면·미래 그래프의 목표선 | 높음 | **P1** |
| 기후 금융 | 직접 없음 | 정책 카드(설명) | 낮음 | 도감 |
| 블루카본(잘피·갯벌·맹그로브) | 엔진에 해양 생태 흡수 없음 | 바다 구역 잘피밭(이미 있음) 확대 — **값 없이** | 중간(시각만) | **P2** |
| 대체육·배양육 | 메탄 위주 → 엔진 밖(문헌값 1-4-2) | 도감 카드 | 낮음 | 도감 |
| 화학적(열분해) 재활용 | 정량 근거 없음 | 분리배출 미니게임 끝 화면에 '미래 기술' 한 줄 + 도감 | 낮음 | 도감 |

- **P1** = 4차 필수. **P2** = 4차 안에서 시간이 남으면(세이브포인트에 미룬 사유 기록). **도감** = 숫자 없는 설명 카드(§2-3).

## 2. T1 — 카드 데이터 · 계산 `js/society-core.js` + `tools/test_society.js`

DOM 없음. 조감도 나중에 쓸 수 있게 `js/` 에 둔다. 로드 순서는 `earth-system.js` 뒤, `actions-core.js` 앞(1인칭 HTML·빌더 `FP_JS` 같이).

### 2-1. 기술 카드 → 레버

```js
// 단계 값은 '2050년 목표'(엔진 직접 설계와 같은 뜻 — 2024년 현재값에서 2050년까지 선형, 이후 유지)
// 단계 수치는 이 프로그램이 정한 연출값(등록부 society_card_levels, assumption). 고등학생 모드는 슬라이더로 연속값.
const TECH_CARDS = [
  { id: 'renew',   label: '태양광·풍력',          lever: 'renewShare',  levels: [0.30, 0.55, 0.80], src: 'ember_ger_2024' },
  { id: 'nuclear', label: '원자력·소형모듈원전', lever: 'nuclearShare', levels: [0.09, 0.15, 0.25], src: 'ember_ger_2024', issue: 'nuclear' },
  { id: 'ev',      label: '전기차·차세대 배터리', lever: 'ev',          levels: [0.03, 0.50, 1.00], src: 'iea_gevo_2024' },
  { id: 'ccus',    label: '공장 굴뚝 탄소 포집(CCUS)', lever: 'ccs', part: 'ccus', levels: [0, 0.5, 1.5], unit: 'GtC/년', issue: 'capture' },
  { id: 'dac',     label: '직접공기포집(DAC)',    lever: 'ccs', part: 'dac',  levels: [0, 0.3, 1.5], unit: 'GtC/년', issue: 'capture' },
  { id: 'industry',label: '산업·항공·해운 전환',  lever: 'otherCut',    levels: [0, 0.4, 0.8],
    sub: ['수소환원제철', '저탄소 시멘트', '지속가능항공유(SAF)', '친환경 선박 연료', '건물 효율'] },   // 하위 항목은 설명만(아래)
  { id: 'forest',  label: '숲 되살리기(자연 기반 해법)', lever: 'forest', levels: [1.30, 0, -1.0], unit: 'GtC/년', src: 'emis_gcp' },
];
```

- **전력 구성 정합**: `fossilShare = max(0, 1 − nuclear − renew)`. 원자력 + 재생 > 1 이면 두 카드 단계를 같은 비율로 줄여 합 = 1(화석 0). 화면에 "전력의 100 %가 무탄소예요" 표시.
- **포집 합**: `ccs = ccus + dac`, 엔진 범위 0~3 GtC/년(`LEVER_RANGE.ccs`)으로 자른다.
- **'산업·항공·해운 전환'의 하위 항목은 숫자로 나누지 않는다.** 엔진의 `otherCut` 은 '전력·도로 밖 나머지 배출(전체의 44 %)'을 한 덩어리로 줄이는 레버다. 하위 항목마다 따로 계산하려면 CO₂ 기준 부문 비중이 필요하다. 지금 확보한 OWID 비중은 **온실가스(CO₂eq) 기준이고 전력 사용분이 부문에 배분된 값**이라(철강 7.2 %에는 철강이 쓴 전기도 들어 있음) 전력 레버와 이중 계산이 된다(6부 6-2).
  → 하위 항목은 '이 덩어리 안에 무엇이 있나'를 보여 주는 **비중 막대(참고)** 와 설명으로만 쓴다. 계산은 카드 단계 하나로 한다.
- 엔진 기준선 주의: 직접 설계는 **2023년 배출 구조를 그대로 유지하는 사회**에서 출발한다. 아무 카드도 안 쓰면 2100년 601 ppm으로, 현재 정책 SSP2-4.5(548 ppm)보다 높다(6부 6-3). 회의실 화면에 "카드를 하나도 안 쓰면 = 지금 그대로 계속" 이라고 밝힌다.

### 2-2. 정책 카드 (열쇠 — 마스터 D16 기본)

| id | 카드 | 하는 일(게임 규칙) | 설명 근거 |
|---|---|---|---|
| `carbon_price` | 탄소 가격제(탄소세·배출권 거래) | 산업·항공·해운 전환, CCUS의 **최대 단계**를 연다 | 원리 설명 + 쟁점(가계 부담·역진성 ↔ 감축 비용 효율) |
| `border` | 탄소국경조정(CBAM) 같은 무역 규제 | 산업 전환 최대 단계를 연다(탄소 가격제와 함께) | EU 제도 사례 설명 |
| `grid` | 전력망·에너지 저장 투자(ESS·스마트그리드) | 태양광·풍력 **최대 단계**를 연다 | 간헐성 보완 설명 |
| `phaseout` | 석탄 발전 단계적 폐쇄 | 원자력·재생 카드 단계가 올라가면 화석 비중이 자동으로 내려간다는 것을 화면에 강조(계산 변화 없음 — 이미 정합 규칙) | |
| `ndc` | 국제 협약·국가 감축목표(NDC) | 회의실 화면에 목표선 표시 + 비교 경로 계산(§2-4) | 한국 2030·2035 NDC |
| `finance` | 기후 금융·국제 협력 | (규칙 없음) 세계 규모 전환에는 개발도상국 지원이 필요하다는 설명 | |

- **'열쇠' 규칙은 연출이다**(등록부 `policy_unlock`, assumption). 실제로는 정책과 기술 보급의 관계가 훨씬 복잡하다. 카드 뒷면에 "이 규칙은 '정책이 기술 보급의 조건이 된다'는 생각을 단순하게 표현한 것이에요"를 적는다.
- 마스터 D16을 '설명만'으로 바꾸면 열쇠 규칙 없이 모든 단계가 열려 있고, 정책 카드는 도감처럼 설명만 한다.

### 2-3. 기후테크 도감 (숫자 없음)

`대체육·배양육`, `화학적 재활용`, `블루카본`, `기후 금융`, `그린수소`, `차세대 배터리` 등. 카드마다 무엇인지, 어떤 배출을 줄이는지, 아직 어려운 점, "이 프로그램의 엔진이 계산하지 않는 이유"(예: 대체육 = 주로 메탄을 줄임, 엔진은 CO₂만 계산)를 적는다. 출처는 등록부. 사실 문장마다 출처가 없으면 넣지 않는다.

### 2-4. 비교 경로 — "전 세계가 한국 NDC와 같은 비율로 줄인다면?"

- 2023년 실제 배출에서 2035년 = 2018년 화석 배출 × (1 − 감축률)까지 직선. 감축률은 53 %·61 %(2035 NDC 범위) 두 줄. 그 뒤 2050년 순배출 0까지 직선(2050 탄소중립 목표를 따른다고 가정), 이후 0 유지. 토지이용 배출은 현재 정책 경로 그대로.
- **가정 세 가지를 화면에 밝힌다**(등록부 `ndc_global_path`, assumption): ① 한국 목표는 국가 단위·온실가스 전체 기준인데, 전 세계 화석 CO₂에 같은 비율을 적용했다 ② 2035~2050 경로 ③ 토지이용은 그대로.
- 엔진 결과(6부 6-3): 2100년 약 370 ppm · 1.07~1.09 °C.

## 3. T2 — 기후 정책 회의실 무대 (M1 무대 틀 사용, 품질 기준 M §6 그대로)

### 3-1. 세계 속 외관

- 도시 구역의 시청 건물(2000년 도시 규모에서 이미 있는 건물. 카페 건물과 다른 것). 정면 기둥, 계단, 깃대, 간판 '미니지구 시청'. 드로우콜 +8 이하.
- "E: 기후 정책 회의실 들어가기". **들어갈 수 있는 것은 현재뿐**(M §0-3과 같음).

### 3-2. 실내 무대 (미터 축척, 약 8 × 5 × 3.5 m)

| 묶음 | 소품 | 품질 메모 |
|---|---|---|
| 회의 탁자 | 긴 원목 탁자(둥근 모서리, 상판 두께 5 cm) + 의자 8개 + 명패 | 의자는 인스턴싱 |
| **탁자 위 디오라마** | 미니 지구 축소 모형(바다·녹지·도시 3구역 — 조감 아크릴 모형의 축소판 느낌) | **이 장면의 주인공.** 카드를 놓을 때마다 모형 위의 풍력 날개·태양광·숲·포집 설비·굴뚝 연기가 실시간으로 바뀐다(T3 세계 규칙과 같은 함수) |
| 카드 | 탁자 위 카드 더미(기술 7 · 정책 6) — 두께 있는 카드(둥근 모서리), 앞면 캔버스 그림, 놓을 칸(디오라마 구역 옆 슬롯) | 들면 살짝 휘어지는 연출(정점 변형)은 선택 |
| 화면 | 벽 화면 2개: ① 2026~2100 CO₂·기온 편차 그래프(기준 사회 / 우리 사회 / NDC 비교선) ② 전력 구성 막대 + 2050 배출량 | 캔버스 텍스처를 카드가 바뀔 때만 다시 그림(매 프레임 아님) |
| 쟁점 판 | 탁자 끝 이젤에 쟁점 카드(찬성·우려 두 칸) | 원자력·포집 카드를 놓으면 자동으로 해당 쟁점이 펼쳐짐 |
| 실내 | 큰 창(바깥 도시가 흐리게 보이는 배경판), 나무 바닥, 천장 조명 | |

### 3-3. 흐름

1. 들어가면 카메라가 탁자 위를 내려다보는 자세. 안내: "2050년 우리 사회를 설계해 보세요. 카드를 모형 옆 칸에 놓으면 미래가 바뀌어요."
2. **카드 놓기**: 카드 더미에서 끌어 칸에 놓기(키보드: 카드 고르기 → 1·2·3 단계). 같은 카드를 다시 누르면 단계가 오르고, 열쇠가 없으면 최대 단계가 잠긴 표시 + "탄소 가격제 카드가 필요해요".
3. 놓을 때마다 디오라마가 0.6초 안에 바뀌고 화면 그래프가 다시 그려진다. 2100년 기온 편차 숫자는 크게 보인다. 중학생 모드에서는 '1.5 °C 목표 / 2 °C 목표 / 넘음' 세 칸 표시로 바꾼다.
4. **쟁점 카드**: 원자력·포집 카드를 처음 놓으면 이젤 쟁점이 펼쳐지고, 학습지 [우리 사회] 탭에 "나는 이 카드를 왜 골랐나" 칸이 열린다(쓰지 않아도 진행 가능).
5. **확정**: [이 사회로 미래 보기] → 사회의 선택에 **'우리가 설계한 사회'** 로 저장(F3 선택지에 추가) → 회의실을 나와 `goTo(2050, 'base')` 또는 2100.
6. 다시 들어오면 마지막 설계가 탁자에 그대로.
