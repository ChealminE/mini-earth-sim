# 4차 E — 시간 이동

> 마스터 규칙을 따른다. 이 단계의 목적: 학생이 **과거 · 현재 · 미래를 오가며 같은 자리를 다시 잰다.**
> 지금은 설정창 안에 연도 슬라이더가 숨어 있다(3차 E4). 이것을 화면의 주 조작으로 올리고, 연도가 바뀌면 세계가 **한 통로**(C5의 `applyWorldState`)로 바뀌게 한다.

## 1. E1 — 타임라인 막대 `firstperson/fp-timeline.js`

- 위치: 화면 위 가운데(HUD·단축바·미니맵과 안 겹치게, D3-3). 학습지가 열려도 3D 칸 위 가운데에 남는다.
- 구성:
  - **정거장 버튼**: 1850 · 1950 · 2000 · **현재(2026)** · 2050 · 2100. 지금 정거장은 눌림 표시(`btn--time` `.is-on`).
  - 정거장 사이 **세밀 조정 슬라이더**(1750~2200, 1년) — 정거장 버튼 줄 아래 얇게.
  - 미래 쪽에 **갈래 전환** [기준 미래 | 나의 미래] — F3 전에는 '기준 미래'만 켜져 있고 '나의 미래'는 비활성 + "현재에서 행동을 고르면 열려요" 안내.
  - 오른쪽 끝에 지금 연도 큰 숫자 + 갈래 이름.
- 조작: 포인터 잠금 중에는 **[ · ]** 키로 정거장 이전/다음(D4). 마우스로 누르려면 F로 학습지를 열어 잠금을 푼다 — 막대에 그 안내를 작게.
- 과거(≤ 2023)는 '실제 배출', 현재~미래는 고른 경로라는 표시: 막대의 과거 구간은 회색 채움, 미래 구간은 파란 점선(조감 2차 F3 시간 막대와 같은 약속).
- 지금 설정창의 `#fpScenario`·`#fpYear`·`#fpGlobalCo2` 는 삭제한다. **경로 선택은 F3의 '사회의 선택'** 으로 옮긴다(E에서는 기본 현재 정책 고정).

## 2. E2 — 연도 → 세계 상태 한 통로

```js
// fp-main.js — 연도·갈래가 바뀌는 길은 이것 하나
function goTo(year, branch) {
  const s = FPModel.sample(year, runOf(branch, year));   // runOf: 아래 '현재까지는 하나의 역사'
  applyWorldState(s);                                    // C5
  FPTimeline.show(year, branch);
  HUD.setYear(year, branchLabel(year, branch));
}
```

- **현재까지는 하나의 역사**(마스터 D6): `year ≤ NOW_YEAR` 이면 언제나 **기준 경로 실행**의 값을 쓴다. 갈래·사회의 선택은 2027년부터만 다르다.
  까닭: 프리셋 경로들은 엔진 조화 규칙 때문에 2024년부터 조금씩 갈라진다(2026년 CO₂ 425.3 / 424.6 / 423.7 ppm — 현재 정책 / 파리협약 / 1.5 °C). '현재'가 고른 미래에 따라 달라지면 안 되므로 1인칭 표시 규칙으로 막는다. 엔진은 고치지 않는다.
  2026 → 2027 사이에 생기는 작은 이음(2 ppm 안팎)은 등록부 `fp_now_join`(assumption) 에 밝힌다.
- 전환 연출: 0.4초 화면 덮개 + 가운데 '2100년 · 기준 미래'. `prefers-reduced-motion` 이면 덮개 없이 바로. 전환 중 측정 클릭은 무시.
- 경로 실행 캐시: 경로(사회의 선택 × 행동 조합)마다 `EarthSystem.run` 한 번(450년 계산 약 10 ms). 행동을 바꿀 때만 '나의 미래' 캐시를 버린다.
- 주소 매개변수 `?scenario=&year=&levers=` 는 계속 받는다(조감 [1인칭으로] 링크). 조감 현재 실태의 [1인칭으로] 링크 연도는 `LAST_HIST_YEAR`(2023) → **`NOW_YEAR`(2026)** 로(마스터 §4의 예외 — 링크 연도만).
- 측정 중(계측기 수렴 중)에 연도가 바뀌면 그 측정은 취소한다(다른 해의 값이 섞이지 않게).

## 3. E3 — 기록에 연도 · 갈래

- 측정 기록 한 줄에 **연도·갈래(과거/현재/기준 미래/나의 미래)·사회의 선택(경로 키)** 를 붙인다. 열 정리는 G1.
- 지점별 평균·표준편차 표는 **(연도, 갈래, 구역, 지점, 항목)** 으로 묶는다 — 다른 해 값끼리 평균하지 않게.
- 현장 과제 ⑤~⑦의 연도 `[2023, 2100]` → `[NOW_YEAR, 2100]`, [O년으로 가기] 버튼은 `goTo(y, 'base')`.
