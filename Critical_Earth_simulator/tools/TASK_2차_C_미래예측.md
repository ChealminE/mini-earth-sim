## §1. 화면 배치 (C1)

**스크롤 없음**이 최우선이다. 뷰포트 1280×720 ~ 1920×1080에서 세로·가로 스크롤이 없어야 한다.
`height: 100dvh` 그리드로 잡고, 각 칸 안에서도 넘치지 않게 그래프 높이를 칸에 맞춘다.

```
┌─────────────────────────────────────────────────────────────────────────┐
│ [← 처음으로]  미니 지구   [현재 실태] [미래 예측] [직접 실험]                     │ 머리줄 (이동)
├───────────────┬───────────────────────────────┬─────────────────────────┤
│ 시나리오        │                               │ 대기 CO₂ ⓘ       [보조]  │
│ ┌──┐┌──┐┌──┐  │                               │ ━━━━━━━━━━│┄┄┄┄┄  ●421  │
│ │🌐││🤝││🎯│  │       인간활동 지구 (3D, 크게)    │ 기온 편차 ⓘ              │
│ └──┘└──┘└──┘  │                               │ ━━━━━━━━━━│┄┄┄┄┄  ●+1.2 │
```

(그림 속 아이콘 글자는 자리 표시일 뿐이다. 실제로는 B §3의 SVG 아이콘을 쓴다.)

- 왼쪽 패널 폭 약 260~300 px, 오른쪽 그래프 열 약 32~38%, 가운데 3D가 나머지.
- 1280×720처럼 낮은 화면에서는 그래프 4개를 2×2로 바꾸는 등 스스로 조정한다. 어떤 해상도에서도 그래프 하나의 높이가 너무 작아(약 110 px 미만) 읽을 수 없게 되면 안 된다.
- 탭 제목 아래 설명은 **한 줄**만 남긴다(예: "1750년부터 2200년까지, 사람이 내보낸 탄소가 지구를 어떻게 바꾸는지 재생해 보세요.").
  지금의 긴 안내문(`futureHint`)과 모형 설명(`modelNote`)은 지우고, 내용은 A5 등록부의 `model_*` 항목 `note` 로 옮긴다(ⓘ에서 보인다).

## §3. 시나리오 그룹 + 직접 설계 (C3)

**시나리오 그룹** — 시나리오·정책 영역(`--ctl-scen`) 버튼 3개를 한 덩어리로.

| 키 | 레이블 | 작은 글씨 | 아이콘 방향 |
|---|---|---|---|
| `ssp245` | 현재 정책 | SSP2-4.5 | 지구 |
| `ssp126` | 파리협약 2 °C | SSP1-2.6 | 협약(악수 또는 문서) |
| `ssp119` | 1.5 °C 탄소중립 | SSP1-1.9 | 과녁 또는 균형 |

각 카드에 ⓘ(`ssp_emissions` 항목, 시나리오별 설명). 선택된 카드는 눌림 상태. 기본 선택은 `ssp245`.

**직접 설계** — 그룹 아래 가는 선으로 나누고, 큰 카드 하나(샌드박스·건축 아이콘 + "직접 설계" + "정책을 골라 나만의 미래 만들기").
누르면 왼쪽 패널이 레버 패널로 바뀐다. 맨 위에 `← 시나리오로` 버튼.

**레버 패널** — 줄마다 `아이콘 · 이름 · 조작 · 값 · ⓘ`. 위쪽에 "2024년부터 적용, 값은 2050년 목표" 한 줄.

| 레버 | 아이콘 방향 | 조작 |
|---|---|---|
| 전기차 비율 | 자동차 + 번개 | 슬라이더 |
| 전력 구성 (화석 / 원자력 / 재생) | 공장 굴뚝 / 원자 / 해 | 합 100% 를 유지하는 한 덩어리 조작(3구간 막대 끌기 또는 슬라이더 3개 연동) |
| 탄소포집 | 포집기(관 + 화살표) | 슬라이더 |
| 산림 | 나무 | 벌채 지속 ↔ 벌채 중단 ↔ 대규모 조림 |
| 기타 배출 감축 | 건물 | 슬라이더 |

- 값 표시는 정보(`.readout`)다. 조작 요소만 버튼·슬라이더 모양.
- 레버 값의 ⓘ는 해당 `lever_*` 항목. `unverified` 면 상자에 경고가 뜬다.
- 레버를 움직이면 궤적을 다시 계산한다(1차 대격변 동작 유지).

## §4. 그래프 4개 (C4)

오른쪽 열에 세로로 4개, x축 1750~2200 공유: **대기 CO₂ / 기온 편차(산업화 이전 대비) / 해수 pH / 해수온**.
측정 요소 4개와 일치한다. 축 범위는 데이터에서 계산한다(하드코딩 금지).

**선의 종류**

| 선 | 구간 | 모양 |
|---|---|---|
| 관측 | CO₂: 1750~1978 CMIP6 재구성 + 1979~ NOAA / 기온: 1850~ HadCRUT5(+불확도 띠) / pH: 1989~ HOT | 먹색(`--data-obs`) 실선·점 |
| 인간활동 지구 (모형) | 2024 ~ 예측 전선 | 데이터 색, **점선** |
| 인간활동 지구 (모형, 과거) | 1750~2023 | 기본 숨김. [모형 검증 보기] (보기 영역 토글)를 켜면 옅은 실선 |
| 자연만 있는 지구 | 1750~2200 전체 | 회색(`--data-nature`) 가는 선, 범례에 "자연만 있는 지구" |
| 직전 시나리오 | 2024 ~ 예측 전선 | 아주 옅은 선, 범례 "이전 선택: …". 다른 시나리오를 고르면 갱신 |

해수온은 관측 자료가 없다(이번에 받지 않음). ⓘ에 "모형 계산값, 관측 비교 없음"을 밝힌다.
pH 그래프 머리에 [Ω 함께 보기] 보기 토글(보조축, `--data-omega`)을 둔다. 기본은 꺼짐.

**과거와 예측의 구분**
- x = 2023에 세로선과 작은 머리표 "관측 끝 · 예측 시작".
- 2023 오른쪽 배경에 옅은 빗금(CanvasPattern)과 아주 옅은 바탕색. 그래프 4개와 시간 막대가 같은 표현을 쓴다.
- 예측 구간이 아직 비어 있을 때 빗금 위에 작은 글씨 "▶을 누르면 예측이 그려집니다".

**예측 전선 (frontier)** — 피드백 10번의 핵심.
- 상태 `frontier` 를 둔다. 처음 값은 2023. 예측선(인간활동 지구의 2024~)은 `x ≤ frontier` 까지만 그린다.
- 재생하면 재생 위치와 함께 `frontier` 가 앞으로 간다 → 선이 실시간으로 그려진다.
- 슬라이더로 `frontier` 보다 앞(미래)으로 끌면 그 지점까지 `frontier` 가 늘어난다(끌어서 예측하기). 과거로 끌면 `frontier` 는 그대로.
- 시나리오·레버를 바꾸면 궤적을 다시 계산하고, 예측선은 **2023부터 현재 `frontier` 까지 0.6초 안팎으로 다시 그려지는** 애니메이션.
- 시간 막대의 [예측 지우기] (시간 영역)를 누르면 `frontier = 2023`, 재생 위치 2023.
- 자연 지구 선은 전선과 무관하게 항상 전체를 보여준다(사람이 없으면 미래도 이미 알 수 있다는 대비).

**데이터 레이블** — 피드백 8번.
- 재생 위치의 연도에서 각 그래프에 점 하나와 값 하나(굵게, 단위 포함)를 그린다. Chart.js 플러그인(`afterDatasetsDraw`)으로 직접 그린다.
- 재생 위치가 과거(≤ 2023)면 **관측값**(있을 때)을, 미래면 인간활동 지구 값을 보인다. 레이블에 "관측" / "예측" 작은 꼬리표를 붙인다.
- 같은 값을 다른 곳(3D, 패널, 카드)에 다시 쓰지 않는다.
- 그래프 위에 마우스를 올리면 그 연도의 값을 보여주는 세로 안내선(기본 툴팁 대신 같은 스타일로).

**보조 정보 팝오버** — 지금 화면에 있던 것 중 지우기 아까운 둘은 그래프 머리의 보기 버튼으로 연다.
- CO₂ 그래프 머리 [탄소는 어디로?] → "배출된 탄소는 어디로 갔나" 누적 막대(기존 기능).
- pH 그래프 머리 [바다 속 탄소] → 화학종 분포 막대 + 완충 능력(기존 기능).
- 팝오버는 그래프 열 위로 뜨고, 레이아웃을 밀지 않는다(스크롤이 생기면 안 된다).

## §5. 자연 지구 토글 (C5)

- 분할 렌더를 끄고, 미래 예측 탭은 **씬 하나**만 그린다. 자연 지구 씬은 지연 생성해서 들고만 있는다.
- 3D 영역 아래쪽 가운데에 [자연만 있는 지구 보기] 보기 영역 토글(`aria-pressed`).
  켜면 0.3초 안팎으로 화면이 옅게 덮였다 걷히며(크로스페이드) 자연 지구로 바뀐다. 끄면 되돌아온다.
- 3D 왼쪽 위에 지금 보고 있는 지구를 알려주는 배지 하나: "인간활동 지구 · 현재 정책" / "자연만 있는 지구". 수치는 넣지 않는다.
- 자연 지구가 켜져 있는 동안 그래프의 자연 지구 선을 조금 굵게 강조한다(같은 정보를 3D와 그래프가 같은 색으로 가리키게).
- `prefers-reduced-motion` 이면 전환 애니메이션 없이 바로 바꾼다.
- 미래 예측 탭에서 노란 안개 틴트를 끈다(지적 2). 그 외 3D 표현 변경은 D 단계다.

## §6. 시간 막대 · 예측 전환 효과 · 기록 서랍 (C6)

**시간 막대** (화면 맨 아래, 시간 영역 `--ctl-time`)
- [▶/❚❚] 재생 버튼, 큰 연도 표시(굵게, `tabular-nums`), 연도 슬라이더, 속도 선택(5·10·20년/초), [예측 지우기].
- 슬라이더 트랙: 1750~2023은 실선 채움, 2023~2200은 빗금(그래프와 같은 표현). `frontier` 까지는 빗금 위에 옅은 채움.
- 기본 재생 위치는 2023. ▶를 누르면 2023 → 2200으로 간다. 2200에 닿으면 멈춘다.

**예측 전환 효과** (재생 위치가 2023을 넘어 미래로 들어가는 순간, 한 번)
1. 3D 위쪽 가운데에 띠: **"여기서부터는 예측입니다"** + 작은 글씨 "관측이 아니라, 고른 시나리오로 모형이 계산한 미래". 0.4초 나타남 → 2초 유지 → 0.6초 사라짐.
2. 미래 구간에 있는 동안 3D에 옅은 청사진 격자 오버레이(CSS, 캔버스 위 `pointer-events: none`)와 오른쪽 위 작은 "예측" 배지. 과거로 돌아오면 걷힌다.
3. 시간 막대의 재생 손잡이 모양이 예측 구간에서 바뀐다(예: 테두리 점선).
4. 재생 위치를 과거↔미래로 여러 번 넘나들어도 띠는 **넘어갈 때마다 한 번씩만**, 슬라이더를 끄는 중에는 띠를 띄우지 않는다(끌기를 놓은 뒤에 판단).
- `prefers-reduced-motion` 이면 1번은 페이드 없이 짧게, 2·3번은 그대로.

**기록 서랍** (기록 영역 `--ctl-rec`)
- 시간 막대 오른쪽 [● 기록] — 누르면 지금 연도·시나리오(또는 직접 설계)·보고 있는 지구·측정 요소 4개를 한 줄 저장. 버튼에 기록 개수 배지.
- [기록 보기] — 오른쪽에서 밀려 나오는 서랍(화면을 덮음, 레이아웃을 밀지 않음): 기록 표, [CSV 내보내기], [기록 지우기], [닫기].
- CSV 열은 지금과 같다: `year, scenario, earth, co2_ppm, air_temp, water_temp, ph` (BOM 포함). 표 머리에 각 열의 ⓘ.
