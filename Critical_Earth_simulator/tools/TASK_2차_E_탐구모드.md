# 2차 E — 탐구 모드 (2차 세션)

> 마스터: `TASK_2차_마스터.md`. D 다음에 한다.
> 목표는 이 시뮬레이션을 **학생이 질문을 따라가는 학습 시뮬레이션**으로 쓸 수 있게 하는 것이다.
> 수업 초안은 아직 없다. 그래서 단계는 **코드가 아니라 데이터 파일로** 만들어, 나중에 수업에 맞게 고칠 수 있게 한다.

## §1. 구조 (E1)

- `js/inquiry-steps.js` — 탐구 경로와 단계 정의(데이터만). 교사가 이 파일만 고치면 단계가 바뀌어야 한다.
- `js/inquiry.js` — 단계 실행기. 단계에 적힌 동작(아래 §2)을 화면에 적용하고, 학생 응답을 기록한다.
- 미래 예측 탭 왼쪽 패널 맨 위에 [탐구 | 자유 조작] 전환(이동 영역). 기본은 자유 조작.
  탐구를 켜면 왼쪽 패널이 **경로 선택 → 단계 안내**로 바뀐다. 끄면 자유 조작 패널로 돌아오고 화면 상태를 되돌린다.

단계 정의 형식(예):

```js
{
  id: 'A2',
  title: '증가는 언제 시작됐을까?',
  question: 'CO₂가 늘어나기 시작한 곳을 그래프에서 눌러 보세요.',   // 굵게 보인다
  hint: '선이 위로 꺾이기 시작하는 곳을 찾아보세요.',                  // 접어 둔다
  actions: [
    { do: 'showCharts', charts: ['co2'] },
    { do: 'timeRange', from: 1750, to: 2023, lockFuture: true },
    { do: 'pickPoint', chart: 'co2', saveAs: 'A_turningYear' },
  ],
  next: 'A3',
}
```

## §2. 단계 동작 목록 (E1)

실행기가 지원해야 하는 동작이다. 새 동작이 필요하면 여기에 추가하고 문서화한다.

| 동작 | 하는 일 |
|---|---|
| `showCharts` | 보이는 그래프를 고른다(나머지는 옅게 접음). 스크롤이 생기면 안 된다 |
| `timeRange` | 슬라이더 범위·예측 잠금(`lockFuture`) |
| `overlay` | 그래프에 다른 자료를 겹친다(이중 축). 예: CO₂ 위에 화석연료 배출, pH 위에 CO₂, 기온 위에 CO₂ |
| `pickPoint` | 학생이 그래프를 눌러 연도를 고른다. 고른 연도·값을 `saveAs` 로 저장하고 점을 표시 |
| `revealMarkers` | 숨겨 둔 사건 표지를 공개한다(§4) |
| `setScenario` | 시나리오 선택(또는 학생 선택 대기) |
| `play` | 지정 구간 재생 |
| `toggleNature` | 자연 지구 토글 |
| `focus3D` | 3D 카메라를 대상(도시·산호·조개·빙하)으로 부드럽게 이동 |
| `openPopover` | 그래프 팝오버 열기(탄소는 어디로 / 바다 속 탄소) |
| `askText` | 짧은 글 응답(한두 문장). `saveAs` 로 저장 |
| `askChoice` | 보기 고르기. 정답 판정은 하지 않아도 되고, 하더라도 "다시 생각해 보세요" 수준으로 |
| `impactCards` | 기온 수준별 영향 카드(§5) |
| `record` | 지금 상태를 기록 서랍에 한 줄 저장 |

단계 이동 버튼 [이전] [다음]은 이동 영역. 질문은 굵게, 힌트는 접어서. 단계 진행 표시(예: 3/6).

## §3. 탐구 경로 3개 (E2)

랩미팅에서 제시한 세 학습 과정을 그대로 옮긴다. 문구는 고등학생 수준으로 다듬어도 되지만 흐름은 바꾸지 마라.

**경로 A — 왜 CO₂가 증가했을까?**
1. CO₂ 그래프(1750~2023, 관측)만 보이기. `askText`: "CO₂는 어떻게 변해 왔나요?"
2. `pickPoint`: "증가가 시작된 곳을 눌러 보세요." → 고른 연도 저장.
3. `revealMarkers`: 산업혁명 구간, 1950년 이후 급증 구간을 공개하고, 학생이 고른 연도를 같은 그래프에 표시해 비교.
4. `overlay`: CO₂ 위에 화석연료 배출(GCP) 겹치기 + `focus3D` 도시(D에서 만든 도시 성장). `askText`: "두 그래프는 어떤 관계인가요?"
5. `toggleNature`: "사람이 없었다면 CO₂는 어땠을까요?" (자연 지구 선 강조)
6. `askText`: "CO₂ 증가의 원인은 ____이다." → `record`

**경로 B — 해양 pH는 그동안 어땠을까?**
1. pH 그래프(관측 HOT + 모형 과거)만 보이기. `askText`: "pH는 어떻게 변하고 있나요?"
2. `overlay`: pH 위에 CO₂. `askText`: "두 값은 어떤 관계인가요?"
3. `openPopover`: 바다 속 탄소(화학종 분포). 반응식 CO₂ + H₂O ⇌ H₂CO₃ ⇌ H⁺ + HCO₃⁻ 를 단계 안내에 보인다.
   `askChoice`: "pH가 낮아지는 이유는?"
4. `focus3D` 조개·산호 + pH 그래프의 [Ω 함께 보기] 켜기. "Ω가 1보다 작아지면 무슨 일이 생길까요?"
5. `askText`: "바다가 산성화되는 이유는 ____이다." → `record`

**경로 C — 지구의 대기 기온은 어떻게 변하고 있을까?**
1. 기온 그래프(HadCRUT5 + 불확도) 위에 CO₂ `overlay`. `askText`: "기온은 어떻게 변하고 있나요?"
2. "CO₂가 더 높아지면?" → `setScenario` 학생 선택 대기 → `play` 2024~2100. 세 시나리오를 차례로 해 보도록 안내하고,
   시나리오마다 2100년 값을 자동으로 `record`(비교 표가 기록 서랍에 쌓이게).
3. `impactCards`: 학생이 본 시나리오들이 도달한 기온 수준의 영향 카드(§5). "지구 평균기온이 오르면 인류의 삶은 어떻게 될까요?"
4. `askText`: 토론 질문 한두 개 → `record`

## §4. 사건 표지 (E3)

그래프 위에 겹치는 구간 표지. **처음에는 숨기고**, `revealMarkers` 로만 공개한다(학생이 먼저 판단하게).

| 키 | 표지 | 근거 |
|---|---|---|
| `industrial_revolution` | 산업혁명 | 연도 범위는 신뢰할 수 있는 백과사전·교과서 출처로 정하고 등록부에 넣는다(예: 18세기 중후반~19세기 전반). 출처를 못 찾으면 `unverified` |
| `great_acceleration` | 1950년 이후 급증 ("대가속") | Steffen et al. (2015), *The Anthropocene Review* — 원문 확인 후 `verified` |

표지마다 ⓘ.

## §5. 영향 카드 (E4)

- 기온 수준(1.5 / 2 / 3 / 4 °C)별 카드. 카드마다 영향 2~3개, **수치는 IPCC 문서에서 직접 확인한 것만** 쓴다.
  - 후보: AR6 WG1 정책결정자 요약의 극한 고온·호우 빈도 변화(기온 수준별), SR1.5 정책결정자 요약의 산호초 감소, AR6의 시나리오별 해수면 상승 범위.
  - 각 수치에 문서 이름·그림/표 번호·쪽수를 등록부에 적고 카드에 ⓘ.
  - **발췌본(`docs/refs/발췌/`)과 그 쪽 이미지에서 확인하지 못한 수치는 카드에 넣지 마라.** 필요한 쪽이 없으면 "발췌 추가 필요" 목록에 적는다. 카드 내용이 비면 그 카드를 만들지 않고 PR에 적는다.
- 카드 문구는 고등학생이 읽을 수 있게, 수치 + 한 줄 설명. 공포를 주는 표현은 피하고 사실만.
- **수치의 기준을 카드에 함께 밝힌다.** `체크리스트.md` 에 정리된 주의점:
  - Figure SPM.6(극한 고온·호우)은 **육지** 기준이고, 가뭄은 **건조해지는 지역** 기준이다. 비교 기준은 1850~1900년의 10년(또는 50년)에 한 번 일어나던 사건이다.
  - 해수면 상승 기준 연도가 문서마다 다르다. AR6는 1995~2014 대비(1900 대비로 바꾸려면 각주 35에 따라 +0.16 m), SR1.5는 1986~2005 대비. 두 문서 값을 한 카드에 섞지 마라.
  - AR6 SPM 본문에는 SSP3-7.0의 해수면 수치가 없다(그림 곡선만). 우리 시나리오(SSP1-1.9, 1-2.6, 2-4.5)는 수치가 있다.

## §6. 학생 응답 기록 (E5)

- 탐구 중 저장한 값(`pickPoint` 연도, `askText`·`askChoice` 응답, `record` 줄)을 기록 서랍에 **탐구 기록** 묶음으로 보인다.
- CSV를 두 종류로 내보낸다: 기존 측정 기록, 탐구 기록(`path, step, question, answer, year, value, time`).
  수업 활동지·논문 분석 자료로 쓰인다. 파일 이름에 날짜·시각을 넣는다.
- 브라우저를 새로 고쳐도 탐구 진행·응답이 남게 하려면 `localStorage` 를 쓰되,
  `file://` 에서 막히는 브라우저가 있으니(`build_single_html.py` 의 기존 처리 참고) 실패해도 동작은 계속되게 한다.

## 수용 조건 (E)

- 경로 A·B·C를 처음부터 끝까지 진행한 스크린샷 묶음(단계마다 한 장).
- 탐구 기록 CSV 예시 파일(가짜 응답으로 한 번씩 진행한 결과)을 PR에 첨부.
- `inquiry-steps.js` 만 고쳐서 단계 하나를 추가·삭제해도 동작함을 보이는 짧은 시연(문구 하나 바꾼 커밋을 따로 만들지 말고, 테스트 스크립트로 확인).
- 영향 카드의 모든 수치에 대해 "문서 · 그림/표 · 쪽수" 표. 확인 못 한 항목 목록.
- 탐구를 켰다 꺼도 자유 조작 상태(시나리오·레버·재생 위치·토글)가 원래대로 돌아오는지.
