## 0. 배경 — 왜 바꾸나

2026-10-27 랩미팅 피드백(`docs/refs/10.27_랩미팅_피드백.txt`)과 화면 구성안(`docs/refs/3cha_layout.png`)을 반영한다. 요지:

1. 화면을 **좌측 60 %(3D 모형 + 조작 + 그래프) / 우측 40 %(학습지)** 로 나눈다. 왼쪽은 정보 제공, 오른쪽은 학생이 읽고 쓰는 곳.
2. 아크릴 모형 비중을 줄이고 **그래프 + 인터랙티브 학습지** 중심으로 바꾼다.
3. 학생이 자료 카드를 끌어 놓아 **자기 그래프를 만들고 증거로 쓰는** 작업대를 만든다(동료 교사의 탄소순환 수업).
4. CO₂ 시각화는 《프로젝트 헤일메리》 페트로바 스코프처럼 **가시광 ↔ 적외선 보기 전환**으로 한다(`docs/refs/petrovascope.webp`).

### 사람이 이미 결정한 사항 (바꾸지 말 것)

1. **레이아웃**: 좌 60 % / 우 40 %. 좌측은 위 3D(+시나리오·연도 조작 띠), 아래 그래프. 우측은 학습지.
2. **그래프 순서**: 어디서든 **CO₂ → 기온 → 해수온 → 해수 pH**.
3. **기능은 지우지 않는다.** 화면에서 내리는 것(3D 범례, 자연만 있는 지구, 지시약으로 보기, CO₂ 보기, Ω 함께 보기, 바다 속 탄소)은
   **코드와 기능을 그대로 두고 학습지로 옮긴다.** 기본 화면의 버튼만 사라지고, 학습지 단계(동작)나 학습지 카드에서 켠다. → E §2
   (해석 메모: 10.27 피드백의 "제거"를 사람이 "제거하지 않고 학습지로 넘긴다"로 바꿨다. 애매하면 **코드 삭제 금지**가 기준.)
4. **드래그 앤 드롭 작업대는 공용 모듈**로 만든다. **마우스 전용**(터치 지원 안 함). 키보드 대체 조작은 둔다.
5. **y축**: 서로 다른 변수를 겹칠 때 축 조작으로 상관을 꾸며 낼 수 없게 한다. → C §3
6. **자료 기간 차이**(시작 연도가 자료마다 다름)를 그래프에서 분명히 보인다. → C §4
7. **pH 자료 교체(전 지구 재구성 자료)는 보류.** 지금의 하와이 Station ALOHA 자료를 그대로 쓰고, "한 지점 관측"임을 화면에 밝힌다.
8. **CO₂ 월간 보기는 만들지 않는다.** 연평균만.
9. **미래 예측의 인과 구조는 엔진 설계와 같게**: 조작하는 것은 **배출 경로(시나리오·정책 레버)**, CO₂는 그 결과(매개), 기온·해수온·pH는 최종 결과.
   CO₂를 x축으로 두고 "시나리오와 무관하게 일정한 비례 관계"를 보여 주는 기능은 **만들지 않는다**(과학적으로 틀림). → D
10. **three.js는 `vendor/three.min.js`(r160) 하나로 통일**한다. 1인칭의 CDN 로드를 없앤다. → A §3
11. 페트로바 스코프의 화살표·입자는 **엔진 값에 묶고**, 과장 표시는 배율을 화면에 밝힌다. 후처리(EffectComposer·UnrealBloomPass)는 **쓰지 않는다**. → F
12. 대상은 고등학생, 시간축 1750~2200, 엔진 구조·`PARAMS`·`DT` 불변(1·2차 결정 그대로).

## 3. 작업 방식 (로컬)

### 3-1. 브랜치와 커밋

- `main` 에서 작업 브랜치 `feature/3cha` 를 딴다. 공유 브랜치(`main`, `feature/first-person-mode`)에 바로 커밋·푸시하지 않는다.
- **한 단계씩, 단계마다 커밋.** 메시지 형식 `3차 C2: 그래프 작업대 공용 모듈`.
- 단계가 끝날 때마다 `tools/세이브포인트_3차.md` 표를 **같은 커밋에** 갱신하고 push 한다. 사용량 한도로 끊겨도 다음 세션이 이 파일만 읽고 이어 가게.
- PR은 G에서 연다(`gh` 가 없으면 사람이 연다). **병합하지 않는다.**

### 3-2. 세션 운영 (토큰 절약)

- **한 세션에 한 단계 묶음**(A, B, C처럼 알파벳 하나). 끝나면 사람이 `/clear` 하고 새로 시작한다.
- 큰 파일은 통째로 읽지 않는다. `grep -n` 으로 위치를 찾고 범위만 읽는다.
  특히 **`js/earth-data.js`(생성물, 숫자 배열이 매우 긺)는 읽지 마라** — 구조는 `tools/gen_earth_data.py` 에서 본다.
  `firstperson/fp-world.js`(2,200줄+), `package-lock.json`, `Critical_Earth_simulator.html`(루트, 옛 프로토타입)도 읽지 않는다.
- **스크린샷 반복 확인을 하지 않는다.** 화면은 사람이 실제 브라우저로 본다(아래 3-3).
  Claude는 node 검사·문법 검사·빌드·수치 확인까지만 하고, 화면 확인이 필요한 지점에서 **멈추고 사람에게 볼 것을 구체적으로 요청**한다.

### 3-3. 🧑 사람 확인 체크포인트

지시서에 🧑 표시가 있는 곳에서 Claude는 작업을 멈추고 아래 형식으로 요청한다. 사람이 답하면 이어 간다.

### 3-4. 막혔을 때

- **수치를 억지로 맞추지 마라.** 엔진 `PARAMS` 를 몰래 바꾸지 마라. 기대와 다르면 실제 출력과 함께 보고한다.
- **출처를 지어내지 마라.** 확인하지 못한 값은 등록부(`js/sources.js`)에 `status: 'unverified'` 로 넣고 세이브포인트 "발췌 추가 필요" 목록에 남긴다.
- 의존하지 않는 다음 단계가 있으면 넘어가고(§2 "선행" 열), 의존하면 멈춘다.
- 사람 결정이 필요한 갈림길은 **선택지 2~3개와 각각의 영향**을 적어 묻는다. 혼자 정하지 않는다.

## 5. 공통 수용 조건

세션이 끝나면(또는 멈추면) 아래를 확인하고 **실제 출력값**을 세이브포인트에 적는다. 화면 항목은 사람이 스니펫으로 잰 결과를 받아 적는다.

1. 수정·추가한 js 전부 `node --check`, py 전부 `python -m py_compile` 통과.
2. `node tools/test_earth_system.js`, `test_earth_visual.js`, `test_inquiry.js`, `test_catalog.js`(C1에서 추가), `check_sources.js` 통과.
3. 해수 화학 수치 불변: 25 °C pH 8.184 / 8.042 / 7.908 / 7.710, Ω 4.54 / 3.51 / 2.72 / 1.82 (280/418/600/1000 ppm).
4. 단일 HTML 빌드(`python tools/build_single_html.py`) 성공. **새 js·css를 추가했다면 `AERIAL_JS`/`FP_JS` 목록과 HTML 순서를 둘 다 맞춘다.**
5. 서버에서 `/`, `/dashboard?tab=current|future|live`, `/firstperson/` 가 열리고 콘솔 에러 0건. **직접 실험 탭과 1인칭이 이전처럼 동작.** 🧑
6. **스크롤 없음**: 1280×720, 1366×768, 1440×900, 1920×1080에서 현재 실태·미래 예측 탭 `scrollHeight <= innerHeight`, 가로 스크롤 없음. 🧑(스니펫)
   단, **학습지 패널 내부 세로 스크롤은 허용**(패널 자체가 `overflow: auto`). 문서 전체 스크롤만 금지.
7. **글자 크기**: 현재 실태·미래 예측·시작 화면의 보이는 글자 `font-size` 최솟값 ≥ 13 px. 🧑(스니펫)
8. **대비**: 본문·보조 글자 모두 WCAG AA 4.5:1 이상(`tools/check_contrast.js`).
9. **출처 누락 0**: 화면의 모든 `data-src` 키와 자료 목록의 모든 `src` 키가 `js/sources.js` 에 있다.
10. **드로우콜**: A1에서 잰 기준 대비 페트로바 스코프 꺼짐 상태 +5 이하, 켜짐 상태 +15 이하.
11. **기능 보존**: B3에서 화면에서 내린 6개 기능이 전부 학습지 경로로 켜지고 꺼진다(E2 표). 코드 삭제 0.

## 6. 이 저장소에서 이미 데인 함정 (반복 금지)

1. **Chart.js 축·색 하드코딩 금지** — 축 범위는 데이터에서 계산, 색은 CSS 토큰에서 읽는다.
2. **`build_single_html.py` 목록과 HTML 스크립트 순서가 다르면 빌드가 일부러 멈춘다** — 둘 다 고칠 것.
3. **`CO2_MIN/CO2_MAX` 는 1인칭도 쓴다** — 값을 바꾸지 마라.
4. **`style.css` 는 직접 실험 탭과 공유한다** — 새 규칙은 `css/paper.css`(종이 테마)에 `body.paper` 아래로 쓴다.
5. **뚜껑과 옆벽은 transmission 재질이다** — 반투명 물체는 그 뒤에서 통째로 사라진다(2차 F5 구름 사건). 투명·가산 입자를 상자 안에 넣을 때 반드시 고려(F §1).
6. **`vendor/three.min.js` 는 r160 레거시 UMD 빌드** — `examples/jsm` 의 ES 모듈 애드온(EffectComposer 등)은 클래식 `<script>` + 단일 HTML 빌드와 맞지 않는다. 쓰지 마라.
7. **index.html `?v=` 숫자는 올리지 않는다** — server.py가 파일 내용으로 자동으로 붙인다.
8. **localStorage는 실패할 수 있다**(file:// 단일 HTML 등) — 모든 읽기·쓰기를 try/catch, 실패하면 조용히 메모리로.
   localStorage 용량은 약 5 MB — **그래프 이미지(dataURL)를 저장하지 마라.** 그래프 구성(JSON)만 저장하고 이미지는 필요할 때 다시 그린다.
9. **헤드리스 수치와 실제 화면이 다를 수 있다** — 이번엔 실제 브라우저(사람 확인)가 기준.
10. **테스트 설정 실수를 버그로 오인하지 마라** — 이상하면 테스트 쪽을 먼저 의심.
