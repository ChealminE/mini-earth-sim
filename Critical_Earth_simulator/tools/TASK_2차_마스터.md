## 0. 배경 — 왜 바꾸나

2026-10-23 랩미팅 피드백을 반영한다. 요지는 네 가지다.

1. **UI 전면 개선**: 스크롤 없이 한 화면에 조작부와 핵심 정보, 글자 20% 확대, 다크 → 라이트("문서처럼, 페이퍼처럼, 가독성"),
   조작할 수 있는 것과 정보를 분명히 구분, 조작 영역별 색 구분.
2. **수치 근거**: 화면의 모든 수치에 출처가 있어야 하고, ⓘ에 마우스를 올리면(또는 터치하면) 정확한 데이터셋 출처가 뜬다.
   근거 없는 값은 신뢰할 수 있는 기관 자료로 바꾼다.
3. **학습 시뮬레이션**: 학생이 질문을 따라가는 단계별 탐구에 쓸 수 있어야 한다.
4. **미래 예측 탭**: 첨부 이미지(`docs/refs/future_feedback.png`)의 지적 8개를 반영한다.

### 사람이 이미 결정한 사항 (바꾸지 말 것)

- 자연 지구는 **분할 화면 대신 토글**로 본다. 인간활동 지구 하나를 크게 보여준다.
- 시나리오는 **IPCC SSP 경로**로 교체한다: 현재 정책 ≈ SSP2-4.5, 파리협약 2 °C ≈ SSP1-2.6, 1.5 °C ≈ SSP1-1.9.
- 미래 예측 탭은 **연평균만** 쓴다. 계절 선택기, 농도 고정 모드, 연도 점프 버튼은 **제거**한다.
- 대상은 고등학생, 시간축은 1750~2200, 기온은 2층 에너지 균형 모델(1차 대격변 결정 그대로).

발췌본은 자동 추출 텍스트라 **표는 줄이 깨질 수 있다. 표·그림 값은 같은 쪽의 `.jpg` 이미지를 열어 확인한다.**
필요한 내용이 발췌본에 없으면 추측하지 말고 `unverified` 로 두고, PR에 "발췌 추가 필요: 문서 · 찾는 내용" 목록으로 남긴다.

2차 세션: 1차 세션 PR이 병합돼 있어야 한다(`js/sources.js`, `css/theme.css` 존재로 확인).

그다음 `node Critical_Earth_simulator/tools/test_earth_system.js` 를 돌려 **현재 상태에서 전부 통과**하는지 확인한다.

## 3. 작업 방식

**한 단계씩, 단계마다 커밋한다.** 커밋 메시지는 `2차 A2: 관측 자료 교체` 형식으로 쓴다.
A가 끝나면 세션 작업 브랜치에 **한 번 push** 한다(뒤가 막혀도 근거 정비는 남도록).

### 막혔을 때

- **수치를 억지로 맞추지 마라.** 엔진 파라미터(`EarthSystem.PARAMS`)를 몰래 바꾸지 마라.
  기대와 다르면 실제 출력과 함께 보고한다.
- 의존하지 않는 다음 단계가 있으면 넘어가고, 의존하면 멈춘다(§2 "선행" 열).
- **출처를 지어내지 마라.** 확인하지 못한 값은 등록부에 `status: 'unverified'` 로 넣고 PR에 목록으로 남긴다.
  원문(데이터 파일, readme, 문헌 발췌본과 그 쪽 이미지)에서 직접 확인한 것만 `verified` 다. 문헌은 발췌본의 PDF 쪽 번호를 함께 적는다.

## 5. 공통 수용 조건

세션이 끝나면(또는 멈추면) 아래를 확인하고 **실제 출력값**을 PR에 적는다.

1. 수정·추가한 js 전부 `node --check`, py 전부 `python -m py_compile` 통과.
2. `node tools/test_earth_system.js` 통과 (A §4에서 갱신한 기대값 기준).
3. 기존 해수 화학 수치 불변: 25 °C pH 8.184 / 8.042 / 7.908 / 7.710, Ω 4.54 / 3.51 / 2.72 / 1.82 (280/418/600/1000 ppm).
4. 단일 HTML 빌드(`python tools/build_single_html.py`) 성공. 새 js·css를 추가했다면 빌더 목록과 HTML 순서를 **둘 다** 맞출 것.
   빌더 안의 시작 화면 CSS(`SHELL_CSS`)도 라이트 테마로 바꿔야 한다(B §5).
5. 서버(`python server.py --no-browser --no-serial`)에서 `/`, `/dashboard?tab=current|future|live`, `/firstperson/` 가 200, 콘솔 에러 0건.
   **직접 실험 탭과 1인칭이 이전처럼 열리고 동작하는지** 확인한다.
6. **스크롤 없음**: 뷰포트 1280×720, 1366×768, 1440×900, 1920×1080에서 현재 실태·미래 예측 탭의
   `document.documentElement.scrollHeight <= innerHeight` 이고 가로 스크롤도 없다. Playwright로 측정해 표로 남긴다.
7. **글자 크기**: 현재 실태·미래 예측·시작 화면에서 보이는 글자의 계산된 `font-size` 최솟값 ≥ 13 px.
8. **대비**: 본문 글자색과 배경 토큰 조합이 WCAG AA(4.5:1) 이상. 보조 글자(작은 설명)도 4.5:1 이상.
9. **출처 누락 0**: 화면의 모든 `data-src` 키가 `js/sources.js` 에 있고, 모든 항목에 `url` 이 있다(검사 스크립트로 확인, A §5).
10. 헤드리스에서 WebGL이 멈추면 `#gl` 캔버스만 임시로 숨기고 UI를 찍는다. 코드는 바꾸지 않는다.
    브라우저 설치 자체가 막히면 화면 항목은 "미확인"으로 남기고 계속 진행한다.

## 6. 이 저장소에서 이미 데인 함정 (반복 금지)

1. **Chart.js 축·색 하드코딩 금지** — 축 범위는 데이터에서 계산한다. 색은 이번부터 CSS 토큰에서 읽는다(B §2).
2. **헤드리스 rAF는 약 4 FPS** — 프레임 루프에 의존하는 검증은 거짓이 된다. 엔진·데이터는 node에서 함수로 검증한다.
3. **재질 색은 텍스처에 곱해진다** — 흰색 틴트로는 밝아지지 않는다. 밝은 덮개는 오버레이 메시로 한다.
4. **`build_single_html.py` 목록과 HTML 스크립트 순서가 다르면 빌드가 일부러 멈춘다** — 둘 다 고칠 것.
5. **`CO2_MIN/CO2_MAX` 는 1인칭도 쓴다** — 값을 바꾸지 마라.
6. **`style.css` 는 직접 실험 탭과 공유한다** — 직접 실험 전용 선택자(`#tab-live`, `.live-*`, `.lr-*` 등)는 건드리지 마라.
7. **NOAA 자료는 매달 갱신된다** — 원본 파일 머리말의 버전·생성 날짜를 등록부에 그대로 옮겨라. 추측한 날짜를 쓰지 마라.
8. **HadCRUT5 원본은 1961~1990 기준이다** — 1850~1900 기준으로 바꿔 쓴다(A §2). 기준을 섞지 마라.
9. **테스트 설정 실수를 버그로 오인하지 마라** — 이상하면 테스트 쪽을 먼저 의심할 것.
