## 3. F1 — 표층 해수온 관측 계열 (버그 대응)

### 원인 (코드 읽기로 확인됨)
`js/tab-future.js` `SERIES` 에서 해수온만 `obs: null` 이고, 과거 모형선(`DS.past`)은 기본 숨김이다.
그래서 해수온 그래프는 1750~2023 구간에 **자연 지구 회색 점선 말고는 아무 선도 없다**. 데이터 레이블도 과거에서는 `모형` 꼬리표만 뜬다.
`js/sources.js` `model_sst.note` 에도 "해수온 관측 자료는 이번에 받지 않음"이라고 적혀 있다.

### 할 일
1. 원본: `data/raw/hadsst/HadSST.4.*_annual_GLOBE.csv` (사람이 미리 올려 둠).
   **없으면 이 단계를 멈추고 §3 대안으로 간다.** 파일 이름의 버전 숫자를 등록부에 그대로 옮긴다(마스터 §6-7과 같은 원칙).
2. `tools/gen_earth_data.py` 에 `hadsst()` 추가: 머리줄을 읽어 연도·편차·(있으면) 95 % 불확실성 열을 찾는다. 열 이름을 짐작하지 말고
   실제 머리줄을 보고 맞춘다. 원하는 열이 없으면 `fail()` 로 멈춘다. → `data/sst_hadsst4_annual.csv` (첫 줄 주석에 원본 파일명·버전·기준기간 변환 방법).
3. 기준 변환: HadSST4 원본은 **1961~1990 기준**이다. HadCRUT5와 똑같이 1850~1900 평균을 빼서 1850~1900 기준 편차로 바꾸고,
   그래프에는 `EarthSystem.PARAMS.sst0 + 편차` 로 그린다. `sst0` 값을 읽어 쓰고 **바꾸지 않는다.**
4. `js/earth-data.js` 재생성(`python tools/gen_earth_data.py`) → `EARTH_DATA.sstHadsst`.
5. `js/tab-future.js`: `OBS_PTS.sst`, `SERIES` 해수온 `obs: 'sst'`, 관측 데이터셋 분기(`spec.obs === 'T'` 처럼 불확실성 띠가 있으면 띠까지). y축 범위 계산에 관측값 포함(이미 `sp.obs` 면 들어감).
6. `js/sources.js`: 새 항목 `obs_sst_hadsst4`(org Met Office Hadley Centre, 라이선스 Open Government Licence v3, 인용은 원본 user guide가 지정한 논문 — 저장소 안 자료로 확인 못 하면 `unverified`).
   `model_sst.note` 의 "관측 비교 없음" 문구 고치기, index.html 해수온 ⓘ `aria-label` 도 고치기. `node tools/gen_sources_doc.js` 로 `docs/데이터출처.md` 재생성. `node tools/check_sources.js` 통과.
7. 탐구 경로가 해수온 그래프를 쓰는 단계가 있으면(`inquiry-steps.js` 에서 `sst` 검색) 문구가 "관측 없음"을 전제하지 않는지 확인.

### 예상되는 차이 — 억지로 맞추지 말 것
모형 해수온은 `sst0 + T`(기온 편차를 그대로 더함)라서, 실제 바다 표층보다 **더 빨리 데워지는 쪽으로 어긋날 수 있다**.
이건 모형의 단순화이고 고칠 대상이 아니다. `PARAMS` 를 건드리지 말고, [모형 검증 보기]를 켠 그래프 스크린샷과
2023년 모형값 vs 관측값 숫자를 PR에 적는다. `model_sst.note` 에 이 단순화를 한 문장으로 밝힌다.

### 대안 (원본이 없을 때만)
해수온 그래프에서만 과거 모형선(`DS.past`)을 기본으로 보이게 하고 범례·데이터 레이블에 "모형(관측 자료 없음)"을 붙인다.
PR 맨 위에 "HadSST4 원본 필요"라고 적는다. HOT `temp_c`(하와이 한 지점, 약 25 °C)는 전 지구 평균 18 °C 기준 모형과 6 °C 넘게 차이 나므로 **쓰지 않는다.**

## 5. F3 — 시간 막대 슬라이더 표현

지금: 과거 = 파랑 채움, 미래 = 회색 빗금 + 전선까지 옅은 파랑. 바꿀 것: **과거 = 회색 채움, 미래 = 파란 점선.**

- `css/paper.css` `body.paper #tlScrub` 의 `--track` 만 고친다(`--p-obs`, `--p-front` 는 `updateTrack()` 이 이미 넣음).
  - 과거(0 ~ `--p-obs`): 회색 실선 채움. 그래프의 관측(먹색)과 어울리게 `--ink-3` 계열, 트랙 바탕과 구분되는 진하기.
  - 미래(`--p-obs` ~ 100 %): 트랙 세로 가운데에 **가는 파란 점선**(`--ctl-time`). 그래프의 예측 점선과 같은 표현이 되게.
    예측 전선(`--p-front`)까지는 진하게, 그 뒤 아직 계산하지 않은 구간은 옅게.
  - 구현 힌트: 배경 레이어는 **앞에 쓴 것이 위**다. 점선 레이어(`linear-gradient(to right, 파랑 0 6px, transparent 6px)` + `background-size: 10px 3px` + `repeat-x` + 세로 가운데)를
    맨 아래 전체 폭에 깔고, 그 위에 과거 구간 회색 채움(나머지 transparent)과 전선 뒤 구간을 옅게 덮는 종이색 반투명 레이어를 올리면 범위를 자를 수 있다.
    레이어마다 `background-size/position/repeat` 를 쉼표 목록으로 맞춰야 한다. WebKit·Firefox 트랙 둘 다.
- 손잡이는 지금 그대로(과거 파랑 채움, 미래 점선 테두리).
- 파일 머리 주석 "그래프와 같은 표현"이 거짓이 되지 않게 고친다(그래프의 미래 구간 빗금은 이번에 바꾸지 않음).
- 확인: 2023 / 재생 중 2080 / 2200, 탐구 모드 `timeRange` 로 1750~2023만 보일 때 스크린샷.

## 6. F4 — 기록 효과

- 대상: `js/tab-future.js` `addRecord()`. 인자로 효과 세기를 받게 한다: `addRecord({ fx: 'full' | 'soft' | 'none' })`, 기본 `'full'`.
  `#recAdd` 클릭 → full, `inquiry.js` `doRecord` 의 일반 기록 → full, 재생 끝 자동 기록 → soft. 기존 호출부의 동작(표·CSV·개수)은 바꾸지 않는다.
- 효과는 3D 칸(`#gl-container`) 위 오버레이 하나(`<div class="rec-fx" aria-hidden="true">`)와 CSS 애니메이션으로만. `pointer-events: none`. 3D 렌더러는 건드리지 않는다.
  - **full** (약 0.9초): ① 셔터 플래시 — 흰 막이 0.12초 opacity 0.55 → 0, ② 3D 칸 테두리가 붉게(inset box-shadow 3~4 px) 0.6초 유지 후 사라짐,
    ③ 가운데에 반투명 녹화 표시 — 원형 바탕 + 빨간 점 + "기록 · 2100년" 글자, 살짝 커졌다가 사라짐.
  - **soft**: ②만.
  - 붉은색은 새 토큰 `--rec-flash`(예: 선명한 빨강)를 `css/theme.css` 에 추가한다. 장식이라 대비 기준 대상은 아니지만 가운데 글자는 바탕 위 4.5:1 이상.
- 효과 도중 다시 누르면 처음부터 다시(`void el.offsetWidth` 패턴, `showPredBand()` 와 같은 방식).
- 스크린리더: 기존 `#recCount` 갱신 외에 `role="status"` 문구 "2100년 기록됨" 한 번.
- `prefers-reduced-motion: reduce`: 플래시·크기 변화 없이 붉은 테두리와 가운데 표시만 0.6초 보였다 사라짐.
- 확인: 헤드리스 rAF가 느려도 CSS 애니메이션은 시각 기준이라 동작한다. 누른 뒤 0.05초·0.4초에 스크린샷 두 장.

  ACES 톤매핑에서 흰색이 회색으로 눌리므로 `emissive` 를 약간 주어 **밝은 바탕에서도 하얗게** 보이게 맞춘다(마스터 §6-3: 틴트로는 밝아지지 않는다).
  빙하는 푸른 기가 있는 흰색이므로, 나란히 놓고 봤을 때 구름이 더 희고 부드러워야 한다.
- 움직임: x 방향으로 천천히 흐른다(덩이마다 속도 조금씩 다르게, 0.03~0.06 /초 정도). 상자 안(`±BOX_W/2`)을 벗어나지 않게,
  벽 가까이에서 크기를 줄이며 사라지고 반대쪽에서 다시 커지며 나타난다(감아 돌기). 위치는 뚜껑(`BOX_H − 0.03`) 아래, 지금 높이 근처.
- 성능: 구름 전체를 `InstancedMesh` 하나(드로우콜 1)로. 덩이 이동은 렌더 루프(`stepScene`)에서 인스턴스 행렬만 갱신 — 파도처럼 연출 움직임이므로 렌더 루프에서 해도 된다(상태 계산이 아님).
- 그림자: `castShadow` 는 끈다(움직이는 어두운 얼룩이 오염·연기로 오해될 수 있음). 켜고 싶으면 PR에 비교 스크린샷.

### 8-2. 테두리(3D 칸 주변부) 효과
미래 구간에 있는 동안(`inFuture`), 지금의 파란 테두리 위로 **빛이 테두리를 따라 천천히 도는** 효과를 더한다(한 바퀴 약 4초).
CSS만으로: `.blueprint` 에 `::before` 를 두고 `conic-gradient` + `mask`(테두리 두께만 남김) + `@property --a` 각도 애니메이션.
네 모서리에 짧은 ㄱ자 표시(조준선 느낌)를 두어도 좋다. 과하지 않게 — 3D가 주인공이다. `prefers-reduced-motion` 이면 회전 없이 정지.

### 8-3. 받침대 연산 효과 (핵심)
"미래는 관측이 아니라 지금 계산 중"이라는 느낌을 **지구와 무관한 부분(회전판)**에서 보여 준다.

- 위치: `buildAcrylicScene` 의 회전판(`table`, 반지름 3.6, 윗면 y ≈ −0.005) 윗면 바로 위(y ≈ −0.003)에 원판 하나(`CircleGeometry(3.6, 96)`).
  상자 바닥이 가운데를 덮으므로 실제로 보이는 건 상자 둘레의 띠다.
- 재질: `ShaderMaterial`(`transparent`, `depthWrite: false`). 처음 한 번 캔버스로 만든 **글자 아틀라스 텍스처**(숫자 0~9, `.`, `+`, `−` 정도)를 쓴다.
  프래그먼트 셰이더에서 극좌표(반지름·각도)를 칸으로 나누고, 각 각도 칸이 한 줄기가 되어 **바깥에서 상자 쪽으로 글자가 흘러드는** 매트릭스식 흐름을 만든다
  (줄기마다 속도·위상 다르게, 머리 글자는 진하고 꼬리는 옅게, 글자는 일정 간격으로 바뀜).
- 색: `--ctl-time`(파랑)을 `Theme`/CSS 토큰에서 읽어 uniform으로. 회전판 색(`0xd6cbb4`) 위에서 또렷하되 과하지 않은 불투명도.
- 켜고 끄기: `common.js` 에 `setPredictFx(S, on)` 를 두고, `tab-future.js` `updatePredState()` 에서 `sceneFuture` 와 `sceneNature` **둘 다**에 부른다
  (자연 지구 토글 중에도 같아야 한다). 셰이더 `uFade` 를 0.4초에 걸쳐 0 ↔ 1(렌더 루프에서 보간). `uFade = 0` 이면 메시 `visible = false`(드로우콜 0).
- 시간 uniform은 `stepScene` 에서 `t` 로 갱신. 현재 실태 탭 씬과 직접 실험 탭 씬에는 만들지 않는다(미래 예측 씬만 — `opts` 로 구분, 필요하면 `opts.predictFx`).
- `prefers-reduced-motion: reduce`: 흐름 없이 옅은 정지 글자 무늬만.
- 드로우콜 +1 이내. 마스터 D의 1.5배 규칙을 그대로 적용해 F0 기준과 비교.

### 확인
2023(효과 없음) / 2030(전환 직후) / 2150 스크린샷, 자연 지구 토글 켠 2150, 2023으로 되돌린 뒤 효과가 걷히는지.
움직임은 헤드리스 rAF가 느려 프레임으로 검증할 수 없으므로(마스터 §6-2) `t` 를 두 값으로 고정해 찍은 두 장이 서로 다른지로 확인한다.
