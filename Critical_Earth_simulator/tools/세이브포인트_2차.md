## 이어서 할 사람이 알아야 할 것
- 3D는 전부 `js/common.js` 의 `buildAcrylicScene()` 한 함수(씬마다 하나씩 만듦) + `applyState(S)`(0.2초 틱에서 부름) + `stepScene(S)`(매 프레임 움직임).
  직접 실험 탭도 같은 함수를 쓰므로 **새 표현은 종이 탭(현재 실태·미래 예측) 씬에서만** 켠다.
- 미래 예측 탭의 3D 입력은 `js/tab-future.js` `apply3D(S, s)` / `applyLevers3D`. 자연 지구 씬은 `sceneNature`(토글을 처음 켤 때 생성).
- 기준 드로우콜(D 이전, 1440×900, `lastFrameDrawCalls`, 그림자 패스 포함):
  현재 실태 655 / 미래 예측 현재 정책 1750 626 · 1850 626 · 1950 548 · 2023 548 · 2100 692 · 2200 692 /
  파리 2 °C 2100 674 / 1.5 °C 2100 578 · 2200 644 / 자연 지구 2200 441.
  측정 스크립트는 세션 스크래치에만 있었다 — 다시 만들려면: Playwright(`/opt/node22/lib/node_modules/playwright`),
  chromium `--use-gl=angle --use-angle=swiftshader`, `http-server -p 8765 Critical_Earth_simulator`,
  `page.evaluate("setPreset('ssp245'); setYear(2100); advanceFrontier(2100); FUT.dirty=true")` 뒤 0.7초 기다려 `lastFrameDrawCalls`.
- 산호: SR1.5 SPM PDF 8쪽 B.4.2 원문 확인함 — "decline by a further 70–90% at 1.5°C … larger losses (>99%) at 2°C".
- **새 파일** `js/earth-visual.js` (`EarthVisual` — 엔진 값 → 3D 크기·개수·색 순수 함수, node 검사 `tools/test_earth_visual.js`).
  index.html 스크립트(earth-system.js 뒤, common.js 앞)와 `build_single_html.py` AERIAL_JS 둘 다 넣었다.
- `sceneFor(tab)` 이 `opts = { paper: tab !== 'live' }` 를 씬에 붙이고, `ensureSceneBuilt` 가 그 opts로 만든다.
  `sceneNature` 껍데기는 `opts: { paper: true, nature: true }`. 씬 객체의 `S.paper` 로 새 표현을 가른다.
- 3D 보기 토글 상태는 `common.js` 전역 `VIEW3D = { co2, indicator }`, 버튼 연결은 `main.js bindView3D(id, key)`.
  버튼 자리: `index.html` `.view3d` (3D 왼쪽 아래, 현재 실태 탭은 밝기 조절 위로 52px). 3D 범례는 오른쪽 아래(D7)에 둘 것.
- `state.noTint` 는 없앴다(종이 탭은 S.paper로 판단).
- 바다(종이 탭)는 `common.js applyOceanPaper(S)` 에서 처리: 자연색 고정(SEA_BODY/SEA_SURFACE), 빙하·산호. D5의 조개·지시약도 여기에 넣는다.
  엔진 값 입력은 `setEarthVisual(S, s, soc)` 가 `state.T / omega / ph` 로 넣는다(soc = null 이면 자연 지구: 도시 없음).
- **산호 기준점 결정**: SR1.5 원문 "a further 70–90%" → 100 % 기준을 0 °C가 아니라 1.09 °C(AR6 A.1.2)로 둠. `EarthVisual.CORAL.T_NOW` 하나만 0으로 바꾸면 지시서 원안.
