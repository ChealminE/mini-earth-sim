## 0. 배경 — 왜 바꾸나

원본 요청 `docs/refs/11.05_4차_개편요청.txt`(11.15 추가 요청 포함). 요지:

1. 2인 협동 체제를 끝낸다. 직접 실험 탭은 지금 구현으로 **완성 처리**하고(협동판으로 고정), 이 저장소는 **시뮬레이션 단독판**(현재 실태 · 미래 예측 · 1인칭 탐험)으로 간다.
2. 1인칭 탐험을 세 가지 요건 중심으로 다시 만든다.
   ① 학생이 여러 측정값을 **직접 잰다** ② **과거·현재·미래를 오간다** ③ **'현재'에서 탄소중립 행동**(분리배출·플러그 뽑기·텀블러·대중교통·자전거·비행 자제 등)을 하면 배출이 달라지고 미래가 바뀌는 것을 **체험**한다.
   ③의 텀블러·분리배출은 **직접 해 보는 3D 미니게임**으로 만든다(2026-11-15 추가 요청): 도시 건물 1층 카페에서 음료를 일회용 컵 / 텀블러에 받고, 분리배출장에서 쓰레기를 준비해 수거함에 넣는다. **미니게임의 3D 품질이 좋아야 한다**(M §6).
   **사회의 선택**(2026-11-15 추가 요청 — 인류의 구조 전환 노력·기후테크)도 1인칭에서 체험한다: 시청 '기후 정책 회의실'에서 정책·기후테크 카드로 2050년 사회를 설계하면 미래 세계(해상풍력·지붕 태양광·포집 설비·숲)가 바뀌고, 학생이 그 미래에서 잰다(T).
3. 1인칭의 날씨·계절·밝기 같은 기능은 뺀다. 라이트(종이) 테마와 시인성 중심으로 UI/UX를 크게 고친다. 측정값은 문헌값에 근거한다. 측정 기록은 학습지와 맞춘 .xlsx/.csv로 내보낸다.

### 사람이 이미 결정한 사항 (바꾸지 말 것)

1. **직접 실험 탭은 협동판으로 고정**(태그 `v2.0-collab-final`)하고, 단독판에서는 코드째 지운다. **협동판 저장소의 `main`은 고치지 않는다.**
2. **시작 화면은 3모드**: 현재 실태 · 미래 예측 · 1인칭 탐험. 모드마다 배경을 그 모드에 맞춘다.
3. **1인칭 3요건**(위 ①②③)이 기준이다. 요건에 쓰이지 않는 기능은 뺀다.
   3차의 "코드 삭제 금지" 원칙은 **이번 1인칭 덜어내기에는 적용하지 않는다** — 되돌릴 길은 협동판 태그와 git 히스토리다.
4. **날씨·계절·밝기 기능은 삭제.**
5. **측정값은 문헌값**: 숫자는 등록부(`js/sources.js`)를 거친다. 근거 없는 대응은 `kind: 'assumption'`(연출)으로 밝힌다(EarthVisual 규칙 3 그대로).
6. **라이트 테마를 1인칭 UI에 적용**: 패널·버튼·글자·아이콘·ⓘ. 3D 세계의 빛과 색은 자연스럽게 둔다.
7. **학습지 연계 내보내기**: .xlsx(시트 여러 장) + .csv.
8. **현재 실태 실시간 관측 API는 이번 범위 밖**(§8 보류 메모).
9. **미니게임은 고품질 3D**: 미터 축척의 별도 무대(scene)에서 PBR 재질·환경맵·부드러운 그림자·둥근 모서리 소품·easing 애니메이션. 완료 조건은 M §6 품질 체크리스트(Q1~Q10). 실존 브랜드(카페 이름·로고·대표색)는 쓰지 않는다.
10. **사회의 선택(T)은 엔진 레버에 있는 것만 숫자로 바꾼다.** 레버에 없는 정책·기술(탄소 가격제·기후 금융·블루카본·대체육 등)은 숫자를 지어내지 않고 정책 카드·도감으로 넣는다. 사회적 쟁점(원자력·탄소세·포집)은 찬성·우려 근거를 같은 분량으로 싣는다.
11. 유지: 대상 **고등학생 기본 + 중학생 모드**(D15), 시간축 1750~2200, 엔진 구조·`PARAMS`·`DT` 불변, 해수 화학 수치 불변, 그래프 순서 CO₂ → 기온 → 해수온 → pH, **마우스·키보드 전용**(터치 없음), three.js `vendor/three.min.js`(r160) 하나, 후처리(EffectComposer 등) 없음.

## 6. 이 저장소에서 이미 데인 함정 (반복 금지)

1. **`build_single_html.py` 목록과 HTML 순서가 다르면 빌드가 일부러 멈춘다** — 둘 다 고칠 것. 1인칭에 CSS를 더하면 빌더의 1인칭 CSS 합치기(`CSS["fp"]`)도 고칠 것.
2. **`js/xlsx-lite.js` 는 직접 실험 파일이 아니다** — `downloadBlob` 을 `tab-future.js`·`inquiry.js`·`worksheet.js` 가 쓴다. A3에서 지우지 마라. G에서 1인칭도 쓴다.
3. **`js/worksheet.js` 는 조감 DOM(#wsTabInquiry 등)·Chart.js·GraphWorkspace·Inquiry 에 묶여 있다** — 1인칭에서 그대로 불러오지 마라(D3에서 저장소만 떼어 낸다).
4. **`localStorage['worksheet.v1']` 의 `fp` 묶음은 조감 [기록] 탭의 '1인칭 현장 기록'이 읽는다**(`worksheet.js` renderFp). 구조를 바꾸면 그쪽도 같이 고친다. 모든 읽기·쓰기 try/catch, 실패하면 조용히 메모리로.
5. **한글 자판에서 E=ㄷ, F=ㄹ** — 단축키는 `e.code` 로 받고, 글 칸·목록 상자에 쓰는 중이면 무시한다(3차 E4).
6. **포인터 잠금은 사용자의 클릭에서만 다시 걸린다** — 학습지를 닫을 때 자동으로 잠글 수 없다. "3D를 클릭해 계속" 안내를 띄운다.
7. **`CO2_MIN/CO2_MAX` 상수는 바꾸지 마라**(earth-model.js). 1인칭 연출을 EarthVisual로 바꾸면 `co2k` 쓰는 곳이 줄어드는데, 상수는 그대로 둔다.
8. **index.html `?v=` 숫자는 올리지 않는다** — 서버가 파일 내용으로 붙인다(A4의 작은 서버도 `versioned_html` 유지).
9. **헤드리스 수치와 실제 화면이 다를 수 있다**(swiftshader) — 드로우콜·FPS는 실제 브라우저(사람 확인)가 기준.
10. **TDZ** — 모듈 즉시 실행 안에서 아직 선언 전인 `const`/`let` 을 건드리면 화면 전체가 멈춘다(3차 B1·E1에서 세 번). 복원·초기화는 선언 뒤나 DOMContentLoaded 뒤로.
11. **`vendor/three.min.js` 는 r160 UMD** — `examples/jsm` ES 모듈 애드온은 쓰지 마라.
12. **테스트 설정 실수를 버그로 오인하지 마라** — 이상하면 테스트 쪽을 먼저 의심.
13. **1인칭 세계는 1유닛 = 50 m**(눈높이 0.032) — 컵·병 같은 작은 물체를 세계 축척에 직접 만들지 마라. 미니게임은 미터 축척의 별도 무대(M §1-1).
14. **렌더러는 하나** — 무대에 들어갈 때 바꾼 노출·그림자·`scene.environment` 를 나올 때 반드시 되돌린다(3차 F 적외선 보기처럼 '켜기 전 값 저장 → 복원', 항목 비교로 확인).
15. **투명 재질(transmission)** 은 그 뒤 물체를 한 번 더 그린다 — 무대 안 투명 물체(컵·유리병·진열장·창)는 꼭 필요한 것만. 반투명 물체끼리 겹치면 정렬이 깨진다(2차 F5 구름 사건) — `renderOrder` 를 정해 둔다.
