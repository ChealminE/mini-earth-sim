# 4차 D — UI 골격 · 라이트 테마 · 1인칭 학습지 패널

> 마스터 규칙을 따른다. 이 단계의 목적: 1인칭을 조감과 **같은 디자인 체계**(종이 테마 토큰·버튼 5색·아이콘·ⓘ)로 옮기고,
> 시인성을 높이고, 오른쪽 **학습지 패널**을 만든다. E(타임라인)·F(행동)·G(내보내기)의 화면 조각은 이 골격 안에 들어간다 — 그래서 D가 먼저다.
> 원칙: **테마는 UI(패널·버튼·글자·아이콘)에만.** 3D 세계의 빛·하늘·물 색은 자연스럽게 둔다.
> 배치 원칙은 10.27 랩미팅 결정과 같다: **왼쪽 = 정보(3D), 오른쪽 = 학습지(40 %)**.

## 지금 시인성 문제 (2026-11-05 확인)

- HUD 9줄이 모두 옅은(`dim`) 작은 글자 — 구역·좌표·상태·CO₂ 두 값·자동차·바다 6값·산호 3값·시각/계절/날씨/바람. **재야 할 값(pH·Ω·수온·CO₂)을 HUD가 이미 보여 줘서 측정할 이유가 사라진다.**
- 단축키 9종 안내가 H를 눌러야만 보임(체크리스트 11절 미해결).
- 도구 표시창은 160×96 캔버스 텍스처 — 3D 안에서 작게 보인다.
- 설정창·야장이 각자 다른 모양의 어두운 패널, 긴 안내문.

## 1. D1 — 테마 토큰 · 공용 부품 불러오기

- `firstperson/index.html` 에 조감과 같은 공용 파일을 붙인다(조감 `index.html` 과 같은 순서 규칙):
  CSS `/css/theme.css`(먼저) → `style.css`(1인칭).
  JS `/js/sources.js` · `/js/theme.js` · `/js/icons.js` · `/js/source-tip.js` 를 `earth-data.js` 뒤, `earth-system.js` 앞에.
- 빌더: `FP_JS` 순서 맞추기, **1인칭 CSS 합치기(`CSS["fp"]`)에 `css/theme.css` 를 앞에 붙인다**(지금은 `firstperson/style.css` 와 인라인 스타일만 — 마스터 §6-1).
- `firstperson/style.css` 를 토큰으로 다시 쓴다. 하드코딩 색 0개가 목표(`var(--…)`만). 버튼은 `.btn` + 영역 클래스(`btn--nav`·`btn--time`·`btn--rec`·`btn--view`·`btn--scen`), 글자 크기는 `--fs-1`(13.2 px) 이상.
- 3D 위에 뜨는 패널: 바탕 `--paper-2` 불투명도 0.94 이상 + 가는 `--rule` 테두리. 밝은 하늘 위에서도 대비가 무너지지 않게 **반투명으로 글자를 직접 하늘 위에 두지 않는다.**
- 도구 표시창(계측기 화면)은 기기 화면이므로 어두운 LCD 그대로 두되, 큰 숫자 폰트를 키우고(지금 44 px → 표시창 높이의 55 % 안팎) 단위·상태 글자도 키운다.
- `tools/check_contrast.js` 에 1인칭 토큰 조합 추가(패널 바탕·글자, LCD 바탕·숫자).

## 2. D2 — HUD 재설계 (측정값을 HUD에서 뺀다)

| 남길 것 (왼쪽 위 한 덩어리) | 뺄 것 |
|---|---|
| 지금 구역(바다·녹지·도시) | 좌표·고도(횡단 조사 기록에만) |
| **연도 배지** — 'O년 · 기준 미래/나의 미래/과거/현재'(E·F가 채움) | 전 지구·이 지점 CO₂, 바다 6값, 산호 3값 |
| 든 도구 이름 | 자동차 수, 시각·계절·날씨·바람(B에서 삭제) |

- 측정값은 **도구 표시창**과, 기록될 때 뜨는 짧은 알림(예: "도심 대기 CO₂ 449 ppm · 기록 #12")에만 나온다.
- HUD 글자는 토큰 색·`--fs-2` 이상, `dim` 반투명 글자 금지.
- 십자선은 밝은 하늘·어두운 물 위에서 다 보이게 두 겹(밝은 선 + 어두운 테두리).
- 미니맵은 유지하되 범례 글자를 토큰으로.

## 3. D3 — 공용 저장소 분리 + 1인칭 학습지 패널

### 3-1. 공용 저장소 `js/worksheet-store.js` (DOM 없음)

- `worksheet.js` 안의 저장소 부분(`store` — `localStorage['worksheet.v1']` 읽기·쓰기·옛 `inquiry.v1` 옮기기·try/catch·실패 시 메모리)을 **새 파일로 떼어 낸다.** `worksheet.js` 는 이 모듈을 쓰게 바꾸되 **동작은 그대로**(조감 회귀: `test_inquiry --browser` 통과 필수).
- 1인칭 묶음 `fp` 의 구조(G에서 기록이 들어옴):

```js
fp: {
  tasks:   { [id]: { id, title, link, obs: {연도: 글}, diff, scenario, time } },  // 지금 구조 그대로 (조감 [기록] 탭 renderFp 가 읽음)
  records: [ /* G1 — 측정 기록 */ ],
  actions: { chosen: [...], scale: 'korea', society: 'ssp245', minigames: {...} },  // F·M
  society: { cards: {...}, levers: {...}, savedAt, issueNotes: {...} },             // T (우리가 설계한 사회)
  ui:      { sheetOpen, tab, onboarded, grade: 'high', chapter },              // grade = 마스터 D15
}
```

- 조감 `worksheet.js` 의 `renderFp()` 는 `fp.tasks` 만 읽는다 — 그 형태를 깨지 마라(마스터 §6-4).

### 3-2. 1인칭 학습지 패널 `firstperson/fp-sheet.js`

- 화면 오른쪽 **40 %** 칸. 탭 4개(WAI-ARIA 탭 패턴, ←/→/Home/End — 조감 `worksheet.js` 와 같은 조작): **[과제] [기록] [나의 행동] [우리 사회]**. [우리 사회] 내용은 T5. [나의 행동] 내용은 F, [기록]의 내보내기는 G가 채운다. D에서는 껍데기와 [과제](지금 야장의 탐구 과제·현장 과제 카드를 옮김)·[기록](지금 야장의 기록 표·지점별 평균/표준편차·횡단 조사 그래프를 옮김)까지.
- 열고 닫기: **F**(지금 습관 그대로). 열린 상태에서는 **Esc** 로도 닫는다. **Tab 키는 쓰지 않는다** — 패널 안 초점 이동(키보드 접근성)에 쓰여야 하기 때문. 열면 포인터 잠금을 풀고, 3D 캔버스를 왼쪽 60 %로 줄인다(`fit()` 이 캔버스 칸 크기를 따르게 — 창 크기 대신 칸 크기). 닫으면 3D가 다시 화면 전체, **"3D를 클릭해 계속" 안내**(포인터 잠금은 클릭에서만 걸린다, 마스터 §6-6).
- 지금의 야장 패널(`#fieldPanel`)·설정창(`#settingsPanel`)은 없앤다. 설정창에 남은 것이 있으면(연도·경로는 E의 타임라인으로) 패널 안 작은 절로.
- 패널 안 ⓘ: `srcButton(키)` 로 C6의 등록부 키를 붙인다(측정 지점 설명, 도구 사양).
- 접근성: 패널이 열리면 첫 탭에 포커스, Esc 로 닫기(포인터 잠금 해제용 Esc와 겹치지 않게 — 잠금 중 Esc는 브라우저가 먼저 가져간다).

### 3-3. 배치 수치 (🧑 확인)

- 1280×720: 패널 40 % = 512 px, 3D 768 px. 패널 안 세로 스크롤은 허용, 문서 전체 스크롤은 금지.
- 패널이 닫힌 탐험 상태: 3D 전체 화면 + HUD(왼쪽 위) + 단축바(아래 가운데) + 미니맵(왼쪽 아래) + 타임라인(위 가운데, E1) — 서로 겹치지 않는지.

## 4. D4 — 조작 정리 · 첫 진입 안내

| 키 | 동작 |
|---|---|
| W A S D · Shift · Space | 이동 · 달리기 · 점프/헤엄 |
| 마우스 · 좌클릭 | 시점 · 든 도구로 측정 |
| 1 ~ 4 | 도구 (온도계 · pH미터 · CO₂센서 · 해수분석기) |
| E | 가까운 행동 지점·카페·분리배출장·시청과 상호작용(F2·M·T) |
| F | 학습지 열기/닫기 (열린 상태에서는 Esc 도) |
| [ · ] | 타임라인 정거장 이전/다음(E1) |
| M · R | 미니맵 크기 · 출발점으로 |

- 화면 아래 한 줄에 **늘 보이는 짧은 키 안내**(학습지가 열리면 숨김). H 도움말은 학습지 [과제] 탭 맨 아래 '조작법' 절로 옮긴다.
- **첫 진입 안내** 3장(이동 → 측정 → 시간·행동), 건너뛰기 가능, 본 뒤에는 `fp.ui.onboarded` 로 다시 안 띄움(학습지 '조작법'에서 다시 보기).
- 모든 단축키는 `e.code` 로, 글 칸 입력 중에는 무시(마스터 §6-5).
- 키보드·마우스 전용(마스터 결정 11). README·첫 진입 안내에 "태블릿 터치는 지원하지 않습니다"를 적는다.
