# 3차 C — 그래프 작업대 (공용 모듈)

> 마스터 규칙을 따른다. 이 단계의 목적: 학생이 자료 카드를 끌어 놓아 **자기 그래프를 만들고, 증거로 학습지에 붙이는** 도구.
> 동료 교사의 탄소순환 수업이 이것을 쓴다(예: x축 연도에 대기 CO₂와 화석연료 배출을 겹쳐 상관을 보고 토의 증거로 쓰기).
> **공용 모듈**로 만든다 — 현재 실태 탭이 먼저 쓰고, 나중에 직접 실험 탭이 옮겨 올 수 있게(G의 이관 가이드).

## 0. 원칙

1. **자료와 실행기를 나눈다**(2차 E의 `inquiry-steps.js` / `inquiry.js` 와 같은 방식).
   자료 목록 `js/data-catalog.js` 는 데이터만 있고, 교사가 이 파일만 고쳐 카드를 넣고 뺄 수 있어야 한다.
2. 계산(축 범위·공통 기간·정규화·상관계수)은 DOM 없는 **`GraphWorkspaceCore`** 에 두고 node로 검사한다.
3. **마우스 전용** 끌어 놓기 + 키보드·클릭 대체 조작. 터치는 하지 않는다.
4. 학생이 **축을 조작해 상관을 꾸며 낼 수 없게** 한다(§3). 이것이 이 작업대가 "증거 도구"가 되기 위한 조건이다.

## 1. C1 — 자료 목록 `js/data-catalog.js`

### 항목 형식

```js
// { id, label, short, unit, axis, src, scope, color, minSpan, order, deck, get }
//   axis   : 같은 값이면 한 축을 같이 쓴다. 'ppm' · 'dT'(°C 편차) · 'pH' · 'GtCyr' · 'GtC' · 'omega'
//   src    : js/sources.js 키. 카드·축·증거에 출처가 따라간다
//   scope  : 'global'(전 지구) · 'station'(한 지점) · 'model'(모형 계산) — 카드와 범례에 꼬리표로 보인다
//   minSpan: 축 범위의 최소 폭. 작은 출렁임이 큰 변화처럼 보이지 않게 (§3 R3)
//   deck   : 'core'(기본 카드 4장) · 'carbon'(탄소순환 확장) · 'model'(모형 비교)
//   get()  : [{ x: 연도, y: 값, lo?, hi?, seg? }] — seg는 자료가 이어 붙은 경계 표시용(§4)
```

  (원본 → `gen_earth_data.py` → `EARTH_DATA` → 여기 한 줄 → `node tools/test_catalog.js`).

### `tools/test_catalog.js`

  `core` 4장이 `co2, temp, sst, ph` 순서(마스터 결정 2).

## 2. C2 — 공용 모듈 `js/graph-workspace.js`

### 화면 (현재 실태 그래프 칸 안)

```
┌───────────────────────────────────────────────┬──────────────┐
│ [Y1: 대기 CO₂ ✕] [Y2: 화석연료 ✕]  보기:(시간)(모양 비교)(산점도) │ 자료 카드 덱  │
│ 기간: [전체] [1950~] [1980~]  [공통 기간만]  [pH 축 뒤집기]      │ ▸ 대기 CO₂   │
│ ┌ 분석창 (Chart.js 1개) ─────────────────────────────┐          │ ▸ 기온 편차  │
│ │  여기에 카드를 끌어 놓으세요                         │          │ ▸ 해수온 편차│
│ └──────────────────────────────────────────────────┘          │ ▸ 해수 pH    │
│ 안내 줄: 지금 조합에 대한 짧은 설명 · 출처 ⓘ  [학습지로 보내기]     │ [+ 탄소순환] │
└───────────────────────────────────────────────┴──────────────┘
      약 75 %                                                    약 25 %
```

- **덱 카드**: 이름 + scope 꼬리표 + 작은 모양선(스파크라인). 스파크라인은 **Chart.js 인스턴스를 쓰지 말고** 2D 캔버스에 직접 그린다(카드 10장 × 차트 = 무거움).
  `[+ 탄소순환]`, `[+ 모형 비교]` 로 묶음을 펼친다.
- **분석창**: Chart.js 인스턴스 **하나**를 계속 갱신한다(만들고 부수기 반복 금지).

### API

```js
const ws = GraphWorkspace.create(rootEl, {
  catalog: DATA_CATALOG,      // C1
  maxSeries: 2,                // 시간·산점도 보기. 모양 비교는 3까지
  decks: ['core', 'carbon', 'model'],
  sourceTip: SourceTip,        // 2차 B3의 ⓘ 부품
});
ws.add(id, slot?)  ws.remove(slotOrId)  ws.clear()
ws.setMode('time' | 'shape' | 'scatter')
ws.setRange('all' | 1950 | 1980)  ws.setCommonOnly(bool)  ws.setFlip(id, bool)
ws.getConfig() → { series:[…], mode, range, commonOnly, flips }   ws.loadConfig(cfg)
ws.lock(opts)   // 탐구 단계가 카드·보기를 제한할 때 (E). 예: { deck: ['co2','fossil'], modes: ['time'] }
ws.on('change', fn)   ws.toImage() → dataURL (내려받기 순간에만)
```

### 끌어 놓기 (마우스)
- `pointerdown` 에서 `e.pointerType !== 'mouse'` 이면 무시. 끄는 동안 카드 복제 그림자, 분석창 위에서 Y1/Y2 칸이 강조.
- 놓는 곳: Y1 칸 → Y1, Y2 칸 → Y2, 분석창 가운데 → 빈 칸 먼저(Y1 → Y2), 둘 다 차 있으면 Y2를 바꾼다.
- 같은 자료를 두 번 넣지 않는다. 같은 축(`axis`)끼리는 **한 축에 같이** 그린다(§3 R1).
- `tab-live.js` 의 `cardDrag` / `askMerge` 부분(약 600~690행)을 **읽고 같은 이벤트 흐름**을 쓴다 — 나중에 직접 실험 탭이 옮겨 오기 쉽게. `tab-live.js` 는 고치지 않는다.
- 대체 조작: 카드에 `tabindex=0`, Enter/Space = 추가, 카드의 [＋] 버튼 클릭 = 추가, 칸 칩의 [✕] 또는 Delete = 빼기.

## 3. y축 규칙 (이 작업대의 핵심)

| # | 규칙 | 왜 |
|---|---|---|
| R1 | **같은 `axis` 는 한 축**(기온 편차 + 해수온 편차 → °C 한 축). | 같은 단위를 두 축에 따로 그리면 크기 비교가 거짓이 된다 |
| R2 | 다른 `axis` 둘 → 왼쪽 Y1·오른쪽 Y2. 축 제목 = 변수명 + 단위, **축 글자색 = 계열 색**. | 어느 선이 어느 축인지 헷갈리지 않게 |
| R3 | 축 범위는 **보이는 기간의 그 계열 값으로 자동 계산** + 위아래 5 % 여백 + `minSpan` 보장. **학생이 범위를 손으로 바꿀 수 없다.** | 축을 늘이고 줄이면 아무 두 선이나 겹쳐 보이게 만들 수 있다. minSpan은 pH 0.01의 출렁임이 급변처럼 보이는 것을 막는다 |
| R4 | 축 뒤집기는 **허용하되 숨기지 않는다**: 축 제목 뒤에 "(뒤집음 ↓)", 분석창 모서리 꼬리표, 증거에도 기록. 뒤집기 버튼은 Y2에 pH가 있을 때만 보인다. | CO₂↑·pH↓의 대응을 보기 쉽게 하는 정당한 도구지만, 뒤집었다는 사실이 증거에서 빠지면 오해를 만든다 |
| R5 | **모양 비교 보기**: 공통 기간에서 각 계열을 0~1로 정규화해 한 축에. 축 눈금 대신 "낮음 / 높음", 상단 고정 문구 "모양만 비교합니다 — 크기와 단위는 비교할 수 없어요". 최대 3개. | 단위가 다른 셋 이상을 정직하게 겹치는 유일한 방법 |
| R6 | **산점도 보기**: x = Y1 계열, y = Y2 계열, **공통 연도만**. 점 색은 연도 순(옅음 → 진함)으로 시간 순서를 남긴다. 상관계수 r과 자료 수 n, 기간 표시. 고정 문구 "함께 변한다고 원인이라는 뜻은 아니에요 — 왜 함께 변하는지 설명이 필요해요". | 시간축 두 선의 "비슷해 보임"을 숫자로 확인하게. 인과 비약 방지 |
| R7 | scope가 `model` 이면 **점선**, `station` 이면 범례에 "한 지점" 꼬리표. 관측과 모형이 같은 모양으로 보이지 않게. | 관측 증거와 모형 결과를 구분해야 토의가 정직해진다 |
| R8 | 기간 버튼은 **정해진 세 개**(전체 / 1950~ / 1980~). 자유 확대 없음. | 최근만 잘라 보기는 유용하지만, 임의 구간 고르기는 체리피킹이 된다 |

`GraphWorkspaceCore` 에 `axisRange(points, minSpan, pad)`, `commonPeriod(a, b)`, `normalize(points, period)`, `pearson(a, b)` 를 순수 함수로 두고
`tools/test_catalog.js`(또는 별도 `tools/test_workspace.js`)에서 합성 자료로 검사한다:
minSpan보다 좁은 자료에서 범위 폭 = minSpan / 공통 기간이 없으면 산점도 비활성 / 완전 상관 자료 r = 1, 반대 r = −1.

## 4. 자료 기간 처리 (마스터 결정 6)

- 시간 보기 x축은 **넣은 계열들의 합집합 기간**. 어떤 계열의 자료가 없는 구간은 그 계열 축 쪽에 옅은 빗금 + "자료 없음(1989년부터)" 같은 작은 글자.
- [공통 기간만]을 켜면 x축을 공통 기간으로 줄인다. 산점도·모양 비교는 **항상** 공통 기간.
- 자료가 이어 붙은 경계(`seg`, 예: CO₂ 1978/1979)는 세로 점선 + 마우스를 올리면 "여기부터 NOAA 직접 관측, 앞은 CMIP6 재구성 농도" 같은 출처 설명(ⓘ 상자 재사용).
- 덱 카드의 스파크라인 아래에 기간("1989~2024")을 적는다 — 끌기 전에 기간 차이가 보이게.

## 5. C3 — 현재 실태 탭에 적용

- `#tab-current` 의 기존 그래프 4개(`chartCo2`, `chartTempHist`, `chartPhHist`, `chartFossil`) 자리를 작업대로 바꾼다.
  **기존 차트 코드는 지우지 말고** 작업대가 켜지면 생성하지 않도록 분기(되돌리기 쉽게, `tab-current.js` 머리 주석에 "3차 C3: 작업대로 대체").
  요약 숫자 상자(A2)는 B1 격자에 맞게 3D 칸 아래 또는 조작 띠에 한 줄로. 1280×720에 안 들어가면 화석연료 상자는 덱의 탄소순환 카드로 넘긴다(기능 유지).
- 처음 열었을 때 기본 상태: Y1 = `co2`, Y2 비어 있음, 시간 보기, 전체 기간. 안내 줄 "오른쪽 카드를 끌어 놓아 비교해 보세요".
- **안내 줄**은 조합에 따라 짧은 설명을 띄운다. 문구는 `data-catalog.js` 에 `hints: [{ pair: ['co2','ph'], text: '…' }]` 처럼 데이터로 둔다.
  기본 문구 두 개만 넣는다: `co2+fossil`, `co2+ph`. **결론을 말해 주지 않는다**("함께 오르나요? 언제부터인가요?"처럼 질문으로).
- 3D 연동: 분석창에 마우스를 올린 연도로 3D 장면을 바꾸지 **않는다**(이번 범위 아님). 현재 실태 3D는 지금처럼 최신 관측 상태.

### 검사
- `node tools/test_catalog.js` 통과, 공통 수용 조건 2·4·9.
- 🧑 1280×720·1920×1080: CO₂를 두고 화석연료를 끌어 Y2에 → 두 축 색이 선 색과 같은가 / pH를 Y2에 → 뒤집기 버튼이 나타나고, 누르면 꼬리표가 붙는가 /
  산점도에서 r이 뜨고 공통 기간만 쓰는가 / 기온 + 해수온이 한 축에 그려지는가 / 덱에서 [+ 모형 비교] 카드가 점선으로 그려지는가.

## 6. C4 — 학습지로 보내기 (증거 첨부)

- 안내 줄의 [학습지로 보내기] → `ws.getConfig()` 와 만든 시각·탭을 학습지 저장소(`worksheet.v1`, E1에서 만드는 공용 저장소. C4 시점에는 임시로 같은 키에 `evidence` 배열만)에 추가.
  **이미지(dataURL)는 저장하지 않는다**(마스터 §6-8).
- 학습지 [나의 증거] 탭: 증거마다 카드 하나 — 구성으로 **다시 그린 작은 그래프**, 자동 출처 줄(등록부 `name · org`), 뒤집기·모양 비교·산점도 여부 꼬리표,
  학생 메모 입력란("이 그래프가 보여 주는 것"), [크게 보기](작업대에 다시 불러오기), [PNG 내려받기](그 순간 `toImage`), [삭제].
  증거 카드의 Chart.js 인스턴스는 **탭이 보일 때만** 만들고 탭을 떠나면 `destroy()`.
- 미래 예측 그래프도 같은 버튼을 단다: 구성 `{ kind: 'future', chart: 'co2'|'T'|'sst'|'pH', preset 또는 levers, toYear }`.
  엔진은 결정적이므로 증거 카드에서 `EarthSystem.run` 으로 다시 계산해 그린다(저장할 것은 입력뿐).
- 증거는 최대 12개. 넘으면 "오래된 것부터 지우세요" 안내(자동 삭제 안 함).
