# 2차 B — 디자인 시스템

> 마스터: `TASK_2차_마스터.md`. 키워드는 **"문서처럼, 페이퍼처럼, 가독성"** 이다.
> 세부 디자인은 이 문서의 원칙 안에서 스스로 정한다. 정한 값은 PR에 표로 남긴다.

## 현재 상태 (사전 조사 결과)

- `style.css` 592줄에 CSS 변수가 **0개**다. 색이 전부 하드코딩돼 있다(`#5DCAA5` 50회, `#9198a3` 38회, `#e7e9ec` 32회 …).
- 글자 크기는 11 px(43회), 12 px(29회), 10.5 px(22회)가 대부분이고 9 px까지 있다.
- Chart.js 색과 three.js 배경색도 JS 안에 하드코딩돼 있다.
- `style.css` 는 직접 실험 탭과 **공유**한다. `build_single_html.py` 안에도 시작 화면용 다크 CSS(`SHELL_CSS`)가 따로 있다.

## §1. 디자인 토큰 (B1)

`theme.css` 를 새로 만들어 `style.css` **앞에** 불러온다. 모든 색·글자 크기·간격은 여기 변수로만 정의한다.

**면과 글자 (종이와 먹)**
- `--paper` 바탕(따뜻한 미색), `--paper-2` 패널(조금 더 짙은 미색), `--rule` 구분선, `--ink` 본문, `--ink-2` 보조, `--ink-3` 가장 옅은 글자.
- `--ink-3` 도 `--paper`·`--paper-2` 위에서 **4.5:1 이상**이어야 한다. 대비를 계산하는 작은 스크립트로 확인하고 PR에 표로 남긴다.
- 그림자는 거의 쓰지 않는다. 종이처럼 면은 평평하게, 구획은 가는 선(`--rule`)으로 나눈다.

**데이터 색 (그래프·3D 공통)**
- `--data-co2`, `--data-temp`, `--data-ph`, `--data-sst`, `--data-omega`, `--data-nature`(자연 지구, 회색 계열), `--data-obs`(관측점, 먹색 계열).
- 밝은 바탕에서 서로 구분되고, 색각 이상에서도 구분되도록 명도 차를 둔다(빨강·초록만으로 구분하지 않는다).

**조작 영역 5색** (§3에서 사용). 영역마다 `--ctl-X`(테두리·글자), `--ctl-X-bg`(옅은 바탕), `--ctl-X-on`(눌린 상태) 세 개씩.

| 영역 | 변수 | 해당 조작 | 색 방향 |
|---|---|---|---|
| 이동 | `--ctl-nav` | 처음으로, 탭 전환, 단계 이동 | 먹색 |
| 시간 | `--ctl-time` | 재생, 연도 슬라이더, 속도, 예측 지우기 | 파랑 |
| 시나리오·정책 | `--ctl-scen` | 시나리오 3종, 직접 설계, 레버 | 초록 |
| 보기 | `--ctl-view` | 자연 지구 토글, 그래프 보조선, 밝기, 팝오버 열기 | 보라 |
| 기록 | `--ctl-rec` | 기록, 기록 보기, CSV, 지우기 | 주황 |

데이터 색과 조작 색이 겹치지 않게 한다(예: CO₂ 데이터 색과 시나리오 버튼 색이 같으면 "누를 수 있는 그래프"처럼 보인다).

**글자**
- 기준 크기를 지금보다 **20% 키운다.** `--fs-scale: 1.2` 를 두고 단계별 크기를 `calc()` 로 만든다. 계산 결과의 최솟값은 **13 px**.
- 강조할 곳은 굵게(600~700). 숫자 값·핵심 단어·질문 문장이 강조 대상이다. 문단 전체를 굵게 하지 않는다.
- 글꼴은 **시스템 글꼴만** 쓴다(교실 PC는 오프라인일 수 있다. 글꼴 파일을 내려받지 마라).
  본문 `"Pretendard", "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif`.
  제목에 명조를 쓸지는 스스로 판단하되, 쓴다면 `"Noto Serif KR", "Nanum Myeongjo", "Batang", serif` 처럼 Windows 기본 글꼴로 끝나게 한다.
- 숫자는 `font-variant-numeric: tabular-nums` 로 자릿수를 맞춘다(재생 중 숫자가 흔들리지 않게).

## §2. JS에서 토큰 쓰기 (B1)

- `js/theme.js` 를 새로 만든다: `Theme.color('--ink')` 처럼 CSS 변수를 읽는 함수, 투명도 조절 함수.
- 현재 실태·미래 예측 탭의 Chart.js 옵션 색(축, 격자, 글자, 선)을 전부 `Theme.color()` 로 바꾼다.
  **`Chart.defaults` 를 전역으로 바꾸지 마라.** 직접 실험 탭의 그래프까지 바뀐다. 탭별 옵션 함수에서만 쓴다.
- three.js 배경색·안개색: 현재 실태·미래 예측 탭에서만 `--paper` 계열로 바꾼다. 직접 실험 탭은 지금 색을 유지한다
  (`common.js` 에 탭별 배경을 정하는 함수를 두고, 직접 실험 탭은 기존 값을 넘긴다).

## §3. 버튼 체계 (B2)

규칙은 하나다. **누를 수 있는 것은 모두 버튼 모양이고, 정보는 평평한 글자다.**

- 조작 요소는 반드시 `<button>`·`<input>`·`<select>` 로 만든다. `span`·`div`·`a` 에 클릭 이벤트를 다는 곳을 전부 찾아 바꾼다
  (예: 지금 `← 처음으로` 는 글자처럼 보인다).
- 공통 클래스 `.btn` + 영역 클래스 `.btn--nav`·`.btn--time`·`.btn--scen`·`.btn--view`·`.btn--rec`.
  - 기본: 테두리 1.5 px(영역색) + 옅은 바탕(`-bg`), 모서리 둥금, 최소 높이 36 px(터치 고려).
  - 마우스 올림: 바탕이 한 단계 짙어짐 + `cursor: pointer`.
  - 눌림·선택됨(`aria-pressed="true"` 또는 `.is-on`): 영역색으로 채움 + 글자 흰색.
  - 키보드 포커스: `:focus-visible` 에 2 px 윤곽선. 지우지 마라.
  - 사용 불가: 옅게 + `cursor: not-allowed` + `disabled` 속성.
- 아이콘 버튼도 **글자 레이블을 함께** 단다(학생이 아이콘만 보고 추측하지 않게). 공간이 없으면 레이블을 아이콘 아래 작게 둔다.
- 정보 표시는 `.readout` 같은 클래스로 만든다: 테두리·바탕 없음, `cursor: default`, 마우스 올림 반응 없음.
- 아이콘은 인라인 SVG로 `js/icons.js` 한 곳에 모은다(24×24, 선 굵기 2, `currentColor`). 직접 그린 단순한 도형이거나,
  lucide(ISC 라이선스)를 옮겨 쓴다면 라이선스 문구를 `vendor/LICENSES.md` 에 추가한다. 이모지는 쓰지 않는다(Windows에서 모양이 달라진다).

## §4. ⓘ 출처 상자 (B3)

`js/source-tip.js` 를 새로 만든다. A5의 `SOURCES` 를 읽는다.

- 마크업: `<button class="src-i" type="button" data-src="co2_noaa_gl" aria-label="출처 보기: 대기 CO₂ 지구 평균">ⓘ</button>`.
  숫자·그래프 제목 바로 옆에 작게(지름 18 px 안팎) 둔다. `.btn` 체계와 별개로, 눈에 덜 띄지만 버튼임은 알 수 있게.
- **열림**: 마우스 올림(약 150 ms 지연), 키보드 포커스, **터치(탭)**. 전자칠판에는 마우스 올림이 없다.
  **닫힘**: 마우스가 버튼과 상자 둘 다에서 벗어남, `Esc`, 바깥 탭, 다른 ⓘ 열기.
- 상자는 **버튼 위쪽**에 뜬다. 위 공간이 모자라면 아래로 뒤집고, 화면 밖으로 나가지 않게 좌우를 밀어 넣는다.
  상자 위로 마우스를 옮겨도 닫히지 않아야 링크를 누를 수 있다.
- 상자 내용(위에서 아래로):
  1. 종류 배지: 관측 / 모형 계산 / 상수 / 가정 / 보정값 (배지 색을 종류마다 다르게)
  2. **학생용 한 줄**(`label` + 짧은 설명, 굵게)
  3. 기관 · 데이터셋 · 버전
  4. 인용(`cite`, 작은 글씨)
  5. 링크(`url`, 새 창)
  6. `status: 'unverified'` 면 맨 위에 "출처 확인 중인 값입니다" 경고 줄
- 상자는 문서 전체에 **하나만** 만들어 재사용한다. 평소에는 어디에도 출처 글을 따로 적지 않는다(피드백 요구).

## §5. 시작 화면·현재 실태 탭 적용 (B4)

- **시작 화면**: `select.html` 과 `build_single_html.py` 의 `SHELL_CSS` 를 **둘 다** 라이트 테마로 바꾼다.
  모드 선택 카드는 이동(`--ctl-nav`) 영역 버튼이다.
- **머리줄**(탭 공통): `처음으로` 버튼과 탭 전환 버튼을 이동 영역 버튼으로. 탭 이름 옆 현재 탭 표시는 눌림 상태로.
- **현재 실태 탭**: A2에서 바꾼 자료로 그래프 4개를 다시 그리고, 각 그래프 제목 옆에 ⓘ.
  기온 그래프는 HadCRUT5 + 불확도 띠 + 모형선. **스크롤 없이** 한 화면에 들어가게 배치한다(마스터 §5-6의 4개 해상도).
- 3D 위에 떠 있는 글자·밝기 슬라이더도 라이트 테마에 맞춘다. 밝기 슬라이더는 보기 영역 조작이다.

## §6. 직접 실험 탭 이관 가이드 (B4와 함께)

직접 실험 탭은 이번에 손대지 않는다. 대신 동료가 이어서 적용할 수 있게 `docs/테마_이관_가이드.md` 를 만든다.

- 토큰 표(이름, 값, 용도), 버튼 클래스 사용 예, ⓘ 부착 예.
- `style.css` 에서 직접 실험 전용 선택자가 쓰는 하드코딩 색을 **스크립트로 뽑은 목록**과, 각 색에 대응하는 토큰 제안.
- 직접 실험 탭 JS(Chart.js·three.js)에서 하드코딩 색이 있는 줄 목록.
- 이 문서는 사람이 동료에게 전달한다. 동료 파일을 직접 고치지 마라.

**공유 선택자 처리.** `body`, 머리줄, 공통 패널처럼 모든 탭이 쓰는 선택자를 라이트로 바꾸면 직접 실험 탭 본문까지 바뀔 수 있다.
그럴 때는 `theme.css` 맨 끝에 `#tab-live` 범위로 **기존 다크 값을 고정하는 임시 보호 규칙**을 둔다.
보호 규칙에는 "동료가 이관하면 삭제" 주석을 달고, 이관 가이드에도 이 규칙의 위치와 삭제 방법을 적는다.
머리줄(처음으로·탭 전환 버튼)은 모든 탭에서 새 테마로 보여도 된다.

## 수용 조건 (B)

- 토큰 표와 대비 측정 표(모든 글자색 × 바탕색 조합)를 PR에 남긴다. 4.5:1 미만이 하나도 없을 것.
- 현재 실태 탭·시작 화면의 계산된 글자 크기 최솟값 ≥ 13 px.
- 버튼 5종 × 상태 4종(기본·올림·눌림·포커스) 스크린샷 한 장.
- ⓘ 상자: 마우스 올림, 키보드 포커스, 터치 에뮬레이션(Playwright `hasTouch`) 세 경우에 열리고 닫히는 것을 확인.
- 직접 실험 탭 **본문**(머리줄 제외)이 이전과 똑같이 보이고 동작하는지 전후 스크린샷으로 확인(이번 작업이 공유 파일을 건드리므로).
